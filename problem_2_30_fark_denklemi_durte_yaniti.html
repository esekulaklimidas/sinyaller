Problem 2.30 — Birinci Derece Fark Denklemi ve Dürtü Yanıtı

$$y[n] + 2y[n - 1] = x[n] \quad \implies \quad y[n] = -2y[n - 1] + x[n]$$ Başlangıçta dinginlik (initial rest) şartı altında, sisteme birim darbe $x[n] = \delta[n]$ uygulandığında oluşan çıkış dürtü yanıtıdır ($y[n] = h[n]$). İleriye doğru özyineleme yapılarak her adımda önceki değerin $-2$ ile çarpılıp darbe ile toplandığı görülür. Kapalı form yanıt: $h[n] = (-2)^n u[n]$.

Soru Analizi & Teori Rehberi

Başlangıçta Dinginlik (Initial Rest), Özyinelemeli Çözüm ve IIR Filtre Davranışı

🎯 Soru Bizden Ne İstiyor?

  • Fark Denklemi: $y[n] + 2y[n-1] = x[n]$ olarak verilen 1. derece doğrusal sabit katsayılı fark denklemi.
  • Başlangıç Şartı: Initial Rest (Eğer $n < n_0$ için $x[n]=0$ ise, $n < n_0$ için $y[n]=0$'dır).
  • İstenen: Sistemin dürtü yanıtı $h[n]$'i özyinelemeli hesaplayarak genel formülünü türetmek.

💡 Adım Adım Çözüm Metodolojisi

  1. Dürtü Girişi: $x[n] = \delta[n]$ yazılır $\implies h[n] = -2h[n-1] + \delta[n]$.
  2. Başlangıç Şartı: $\delta[n]=0$ ($n < 0$) olduğu için $h[-1] = 0$'dır.
  3. Özyineleme: $h[0]=1$, $h[1]=-2$, $h[2]=4$, $h[3]=-8 \dots$ şeklinde hesaplanır.
  4. Genelleme: Tümevarım ile $h[n] = (-2)^n u[n]$ elde edilir.
  5. Sistem Analizi: $n < 0$ için sıfır (Nedensel); ancak $|-2| > 1$ olduğundan geometrik patlar (BIBO Kararsız).

Canlı Özyineleme ve Dürtü Yanıtı Simülatörü

n = 0
Dürtü Yanıtı: h[n] = (-2)ⁿ u[n] İki Kutuplu Salınımlı Büyüme (Alternating Divergence)

1. Adım

1. Adım: Denklemin Düzenlenmesi ve Başlangıçta Dinginlik Şartı

Dürtü yanıtı $h[n]$, giriş birim darbe $x[n] = \delta[n]$ iken elde edilen çıkıştır: $$h[n] + 2h[n-1] = \delta[n] \quad \implies \quad h[n] = -2h[n-1] + \delta[n]$$ Initial rest (başlangıçta dinginlik) şartı gereği, darbe gelmeden önce ($n < 0$) sistem çıkışı sıfırdır: $$h[-1] = 0, \quad h[-2] = 0, \quad \dots$$

2. Adım

2. Adım: Adım Adım Özyineleme Tablosu ($n = 0, 1, 2, 3, \dots$)

$n = 0$'dan başlanarak ardışık değerler üretilir:

Özyineleme Aşamaları:
• $n = 0: \quad h[0] = -2h[-1] + \delta[0] = -2(0) + 1 = \mathbf{1} = (-2)^0$
• $n = 1: \quad h[1] = -2h[0] + \delta[1] = -2(1) + 0 = \mathbf{-2} = (-2)^1$
• $n = 2: \quad h[2] = -2h[1] + \delta[2] = -2(-2) + 0 = \mathbf{4} = (-2)^2$
• $n = 3: \quad h[3] = -2h[2] + \delta[3] = -2(4) + 0 = \mathbf{-8} = (-2)^3$
• $n = 4: \quad h[4] = -2h[3] + \delta[4] = -2(-8) + 0 = \mathbf{16} = (-2)^4$
• $n = 5: \quad h[5] = -2h[4] + \delta[5] = -2(16) + 0 = \mathbf{-32} = (-2)^5$
3. Adım

3. Adım: Genel Formülün (Kapalı Biçim) Çıkarılması

Gözlemlenen örüntü $n \ge 0$ için $h[n] = (-2)^n$ şeklindedir. Başlangıçta dinginlik şartı ($n < 0 \implies h[n] = 0$) birim basamak dizisi $u[n]$ ile birleştirildiğinde: $$h[n] = (-2)^n u[n]$$

4. Adım

4. Adım: Z-Dönüşümü ve Kutup (Pole) Analizi ile Doğrulama

Fark denklemine Z-dönüşümü uygulanırsa:

Frekans / Z-Bölgesi Sağlaması:
$$Y(z) + 2z^{-1}Y(z) = X(z) \implies H(z) = \frac{Y(z)}{X(z)} = \frac{1}{1 + 2z^{-1}}$$ $$\text{Kutup: } z = -2, \quad \text{Nedensellik (Initial Rest) ROC: } |z| > 2$$ $$\mathcal{Z}^{-1}\{H(z)\} = (-2)^n u[n]$$
5. Adım

5. Adım: Sistem Özellikleri (Nedensellik ve Kararlılık)

Nedensellik: Nedensel (Causal) ($n < 0$ için $h[n] = 0$)
BIBO Kararlılık: Kararsız (Unstable) ($\sum_{n=0}^\infty |-2|^n = \sum 2^n = \infty$)

Kutup $z = -2$ birim çemberin dışında yer alır ($|-2| > 1$). Sistem sınırlı bir girişe (örneğin birim basamağa) karşılık sınırsız büyüyen çıkış üretir.

Fark Denklemi Çözümü, Dürtü Yanıtı $h[n]$, Konvolüsyon ve Sistem Özellikleri

Doğrusal • Nedensel • BIBO Kararlı
Soru Metni (26 Puan)

Aşağıdaki fark denklemi ile tanımlanan LTI sistemi ele alınız: $$y[n] - 0.25y[n - 2] = x[n] + x[n - 1]$$ Bu soru için sistemin başlangıçta dinginlikte (initially at rest) olduğunu varsayınız ($y[-1]=0, y[-2]=0$).

a) (7p) Sistemin dürtü yanıtı $h[n]$'yi bulunuz.
b) (7p) Sisteme uygulanan giriş $x[n] = \delta[n - 1] + 2\delta[n - 2]$ olduğunda, yukarıdaki fark denklemini doğrudan değerlendirerek çıkışı $y[n]$ bulunuz.
c) (7p) Konvolüsyon toplamı ve (a) şıkkındaki sonucu kullanarak sistemin çıkışını bulunuz. (b) şıkkındaki sonuçla karşılaştırınız.
d) (5p) Sistemin bellekli (memory), doğrusal (linear), nedensel (causal) ve kararlı (stable) olup olmadığını belirleyiniz. Yanıtınızı gerekçelendiriniz.
İnteraktif Doğrulama Laboratuvarı

Dürtü Yanıtı $h[n]$ ve İteratif vs. Konvolüsyon Karşılaştırması

Doğrudan iteratif fark denklemi çözümü ile konvolüsyon toplamının her örnekte (%100 özdeş) çakıştığını canlı izleyin.

1. Dürtü Yanıtı: $h[n] = [\frac{3}{2}(0.5)^n - \frac{1}{2}(-0.5)^n] u[n]$ h[0]=1, h[1]=1, h[2]=0.25, h[3]=0.25...
$h[n]$ Dürtü Yanıtı Stemleri Çift Katlı Kökler: r = ±0.5
2. Çıkış $y[n]$: (b) İteratif Değerlendirme vs. (c) Konvolüsyon $h[n-1] + 2h[n-2]$ Maksimum Hata = 0.000000 (%100 Tam Uyuşum)
(b) İteratif Fark Denklemi Çıkışı (c) Konvolüsyon Toplamı $h[n-1] + 2h[n-2]$
Zirve: n=2 anında y[2] = 3.0
a) Şıkkı (7 Puan) Dürtü Yanıtı $h[n]$

Sistemin Dürtü Yanıtının Bulunması

Dürtü yanıtı $h[n]$, sisteme $x[n] = \delta[n]$ uygulandığında başlangıçta dinginlik koşulu ($h[-1]=h[-2]=0$) altında oluşan çıkıştır: $$h[n] - 0.25h[n-2] = \delta[n] + \delta[n-1]$$

1. Karakteristik Denklem ve Kökler:
$$r^2 - 0.25 = 0 \implies r^2 = \frac{1}{4} \implies r_1 = \frac{1}{2}, \quad r_2 = -\frac{1}{2}$$ Homojen çözüm formu: $$h_h[n] = C_1 \left(\frac{1}{2}\right)^n + C_2 \left(-\frac{1}{2}\right)^n, \quad (n \ge 0)$$
2. Başlangıç Değerlerinin İterasyonla Hesabı:
• $n=0$: $h[0] = 0.25 h[-2] + \delta[0] + \delta[-1] = 0 + 1 + 0 = \mathbf{1}$
• $n=1$: $h[1] = 0.25 h[-1] + \delta[1] + \delta[0] = 0 + 0 + 1 = \mathbf{1}$
3. Katsayıların Belirlenmesi:
$$C_1 + C_2 = 1$$ $$\frac{1}{2} C_1 - \frac{1}{2} C_2 = 1 \implies C_1 - C_2 = 2$$ Taraf tarafa toplanırsa: $2C_1 = 3 \implies C_1 = \frac{3}{2}$, $C_2 = -\frac{1}{2}$.
Nihai Kapalı Form Dürtü Yanıtı:
$$\mathbf{h[n] = \left[ \frac{3}{2}\left(\frac{1}{2}\right)^n - \frac{1}{2}\left(-\frac{1}{2}\right)^n \right] u[n]}$$

Örnek değerler: $h[0]=1, h[1]=1, h[2]=1/4, h[3]=1/4, h[4]=1/16, h[5]=1/16, \dots$

b) Şıkkı (7 Puan) Doğrudan İterasyon

Fark Denkleminin Doğrudan Değerlendirilmesi

Giriş $x[n] = \delta[n-1] + 2\delta[n-2]$'dir. Giriş sürücü terimi $v[n] = x[n] + x[n-1]$ olur:

• $n=0$: $v[0] = x[0] + x[-1] = 0 + 0 = 0$
• $n=1$: $v[1] = x[1] + x[0] = 1 + 0 = \mathbf{1}$
• $n=2$: $v[2] = x[2] + x[1] = 2 + 1 = \mathbf{3}$
• $n=3$: $v[3] = x[3] + x[2] = 0 + 2 = \mathbf{2}$
• $n \ge 4$: $v[n] = 0$
Fark Denklemi Adımları: $y[n] = 0.25 y[n-2] + v[n]$:
$y[0] = 0.25(0) + 0 = \mathbf{0}$
$y[1] = 0.25(0) + 1 = \mathbf{1}$
$y[2] = 0.25(0) + 3 = \mathbf{3}$
$y[3] = 0.25(1) + 2 = 0.25 + 2 = \mathbf{2.25} = \frac{9}{4}$
$y[4] = 0.25(3) + 0 = \mathbf{0.75} = \frac{3}{4}$
$y[5] = 0.25(2.25) + 0 = \mathbf{0.5625} = \frac{9}{16}$
$y[6] = 0.25(0.75) + 0 = \mathbf{0.1875} = \frac{3}{16}$
$y[7] = 0.25(0.5625) + 0 = \mathbf{0.140625} = \frac{9}{64}$
Doğrudan Çıkış Dizisi:
$$y[n] = \{ \dots, 0, \underset{\uparrow n=0}{0}, 1, 3, 2.25, 0.75, 0.5625, 0.1875, \dots \}$$
c) Şıkkı (7 Puan) Konvolüsyon Toplamı

Konvolüsyon Toplamı ile Çıkış ve Karşılaştırma

LTI özelliğinden ötürü çıkış $y[n] = x[n] * h[n]$'dir. Girişi yerine koyalım: $$y[n] = (\delta[n-1] + 2\delta[n-2]) * h[n] = \mathbf{h[n-1] + 2h[n-2]}$$

Örnek Bazında Toplama:
• $n=0$: $h[-1] + 2h[-2] = 0 + 0 = \mathbf{0}$
• $n=1$: $h[0] + 2h[-1] = 1 + 2(0) = \mathbf{1}$
• $n=2$: $h[1] + 2h[0] = 1 + 2(1) = \mathbf{3}$
• $n=3$: $h[2] + 2h[1] = 0.25 + 2(1) = \mathbf{2.25}$
• $n=4$: $h[3] + 2h[2] = 0.25 + 2(0.25) = \mathbf{0.75}$
• $n=5$: $h[4] + 2h[3] = \frac{1}{16} + 2\left(\frac{1}{4}\right) = \mathbf{0.5625}$
• $n=6$: $h[5] + 2h[4] = \frac{1}{16} + 2\left(\frac{1}{16}\right) = \mathbf{0.1875}$
Karşılaştırma ve Sonuç:

Konvolüsyon toplamı ile bulunan tüm $y[n]$ değerleri, (b) şıkkında fark denkleminin doğrudan iterasyonu ile bulunan değerlerle TAMAMIYLA ÖZDEŞTİR (%100 Uyuşum). Bu durum hem (a) şıkkındaki $h[n]$ çözümünü hem de (b) şıkkındaki yinelemeli adımları kesin olarak doğrular.

d) Şıkkı (5 Puan) Sistem Özellikleri

Sistem Karakteristiğinin Belirlenmesi ve Gerekçeleri

1. Bellek (Memory): BELLEKLİDİR (Has Memory)

Çıkış $y[n]$ sadece o anki giriş $x[n]$'e değil, geçmiş çıkış $y[n-2]$ ve geçmiş giriş $x[n-1]$ değerlerine bağlıdır. $h[n] \neq K\delta[n]$ olduğundan sistem hafızalıdır.

2. Doğrusallık (Linearity): DOĞRUSALDIR (Linear)

Denklem sabit katsayılı lineer bir fark denklemidir (LCCDE). Sistem başlangıçta dinginlikte (initial rest) olduğundan süperpozisyon ve homojenlik ilkelerini tam sağlar.

3. Nedensellik (Causality): NEDENSELDİR (Causal)

Başlangıçta dinginlik koşulu gereği, $n < 0$ için $h[n] = 0$'dır. Çıkış hiçbir gelecekteki giriş veya çıkış değerine ($x[n+1], y[n+1]$ vb.) ihtiyaç duymaz.

4. Kararlılık (Stability): BIBO KARARLIDIR (Stable)

Dürtü yanıtı mutlak toplanabilirdir: $$\sum_{n=-\infty}^\infty |h[n]| \le 2 \sum_{n=0}^\infty (0.5)^n = 4 < \infty$$ (Karakteristik kökler $r_{1,2} = \pm 0.5$ birim çemberin içindedir: $|r_i| < 1$).

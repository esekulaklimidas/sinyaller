Ayrık Zaman (Discrete-Time) Oppenheim Problem 2.24 (a) / Şekil P2.24

Problem 2.24 (a) — Kaskat LTI Sistemlerde $h_1[n]$ Dürtü Yanıtının Bulunması

$$h[n] = h_1[n] * h_2[n] * h_2[n], \quad h_2[n] = u[n] - u[n-2] = \delta[n] + \delta[n-1]$$ Üç nedensel LTI sistem birbirine seri (kaskat) bağlanmıştır: $x[n] \to [h_1[n]] \to [h_2[n]] \to [h_2[n]] \to y[n]$. İki $h_2[n]$ bloğunun eşdeğer yanıtı $g[n] = h_2[n] * h_2[n] = \{1, 2, 1\}$'dir. Toplam dürtü yanıtı $h[n] = \{1, 5, 10, 11, 8, 4, 1\}$ verildiğinde, nedensellik kısıtı ve dekonvolüsyon (fark denklemi özyinelemesi) ile bilinmeyen birinci sistemin yanıtı $h_1[n] = \{1, 3, 3, 2, 1\}$ ($0 \le n \le 4$) olarak bulunur.

Soru Analizi & Mini Konu Anlatımı

Kaskat LTI bağlantı, Konvolüsyon Değişme/Birleşme Özellikleri ve Ayrık Dekonvolüsyon

🎯 Soru Bizden Ne İstiyor?

  • Blok Şeması: $x[n]$ girişi sırasıyla $h_1[n]$, $h_2[n]$ ve tekrar $h_2[n]$ bloklarından geçmektedir.
  • Verilenler: $h_2[n] = u[n] - u[n-2]$ ($n=0, 1$ için $1$, diğer yerlerde $0$) ve toplam sistem dürtü yanıtı $h[n]$ (Şekil P2.24(b)).
  • Nedensellik Şartı: Tüm sistemler nedensel (causal) olduğundan $n < 0 \implies h_1[n] = 0$'dır.
  • Hedef: Bilinmeyen $h_1[n]$ ayrık zamanlı dürtü yanıtını hesaplamak.

💡 Adım Adım Çözüm Metodolojisi

  1. Kaskat Birleşimi: $g[n] = h_2[n] * h_2[n]$ hesaplanır. $g[n] = \delta[n] + 2\delta[n-1] + \delta[n-2]$.
  2. Konvolüsyon Toplamı: $h[n] = h_1[n] * g[n] = h_1[n] + 2h_1[n-1] + h_1[n-2]$.
  3. Özyinelemeli Çözüm (Forward Recursion): $h_1[n] = h[n] - 2h_1[n-1] - h_1[n-2]$ formülüyle $n = 0, 1, 2, 3, 4$ sırasıyla çözülür.
  4. Süre Kontrolü: $h[n]$ uzunluğu $7$, $g[n]$ uzunluğu $3 \implies h_1[n]$ uzunluğu $7 - 3 + 1 = 5$ örnektir ($n = 0 \dots 4$).

1. Adım

1. Adım: Blok Şemasının İncelenmesi ve $h_2[n]$ Tanımı

Sistem üç LTI bloğunun ardışık (kaskat) bağlanmasıyla oluşturulmuştur. $h_2[n]$ bloğu $u[n] - u[n-2]$ olup yalnızca iki darbeden oluşur: $$h_2[n] = \delta[n] + \delta[n-1]$$

2. Adım

2. Adım: İki $h_2[n]$ Bloğunun Birleştirilmesi $\to g[n] = h_2[n] * h_2[n]$

Konvolüsyonun birleşme (associative) özelliği gereği, son iki $h_2[n]$ bloğu tek bir eşdeğer sistem olarak düşünülebilir: $$g[n] = (\delta[n] + \delta[n-1]) * (\delta[n] + \delta[n-1]) = \delta[n] + 2\delta[n-1] + \delta[n-2]$$

3. Adım

3. Adım: İleri Doğru Özyinelemeli Dekonvolüsyon (Adım Adım Hesaplama)

$h[n] = h_1[n] + 2h_1[n-1] + h_1[n-2] \implies h_1[n] = h[n] - 2h_1[n-1] - h_1[n-2]$ denklemi nedensellik ($h_1[n<0]=0$) ile çözülür:

Özyineleme Adımları Tablosu:
• $n = 0: \quad h_1[0] = h[0] = \mathbf{1}$
• $n = 1: \quad h_1[1] = h[1] - 2h_1[0] = 5 - 2(1) = \mathbf{3}$
• $n = 2: \quad h_1[2] = h[2] - 2h_1[1] - h_1[0] = 10 - 2(3) - 1(1) = \mathbf{3}$
• $n = 3: \quad h_1[3] = h[3] - 2h_1[2] - h_1[1] = 11 - 2(3) - 1(3) = \mathbf{2}$
• $n = 4: \quad h_1[4] = h[4] - 2h_1[3] - h_1[2] = 8 - 2(2) - 1(3) = \mathbf{1}$
• $n = 5: \quad h_1[5] = h[5] - 2h_1[4] - h_1[3] = 4 - 2(1) - 1(2) = \mathbf{0}$
• $n = 6: \quad h_1[6] = h[6] - 2h_1[5] - h_1[4] = 1 - 2(0) - 1(1) = \mathbf{0}$
Görüldüğü üzere $n \ge 5$ için $h_1[n]$ sıfırdır. $h_1[n]$ sonlu sürelidir (FIR filtresi).
4. Adım

4. Adım: Alternatif Çözüm: Z-Dönüşümü ve Polinom Bölmesi

Zaman bölgesindeki konvolüsyon Z-bölgesinde polinom çarpımına karşılık gelir:

Z-Bölgesi Analizi ($H_1(z) = H(z) / G(z)$):
$$G(z) = (1 + z^{-1})^2 = 1 + 2z^{-1} + z^{-2}$$ $$H(z) = 1 + 5z^{-1} + 10z^{-2} + 11z^{-3} + 8z^{-4} + 4z^{-5} + z^{-6}$$ $$H_1(z) = \frac{1 + 5z^{-1} + 10z^{-2} + 11z^{-3} + 8z^{-4} + 4z^{-5} + z^{-6}}{1 + 2z^{-1} + z^{-2}} = 1 + 3z^{-1} + 3z^{-2} + 2z^{-3} + z^{-4}$$
Kalan sıfırdır ($R(z) = 0$). Ters Z dönüşümü alındığında doğrudan $h_1[n] = \delta[n] + 3\delta[n-1] + 3\delta[n-2] + 2\delta[n-3] + \delta[n-4]$ elde edilir.
5. Adım

5. Adım: Bulunan $h_1[n]$ Dürtü Yanıtının Ayrık Kök (Stem) Grafiği

Sonuç dizisi $h_1[n] = \{1, 3, 3, 2, 1\}$ ($n = 0, 1, 2, 3, 4$). $n < 0$ ve $n \ge 5$ için $0$'dır.

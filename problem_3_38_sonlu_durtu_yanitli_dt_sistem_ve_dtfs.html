Problem 3.38: Parçalı Tanımlı FIR Sistemde DTFS Katsayılarının Hesaplanması

$n \in [0, 2]$ aralığında $+1$, $n \in [-2, -1]$ aralığında $-1$ olan sonlu dürtü yanıtına ($h[n]$) sahip ayrık zamanlı LTI sistemin, $N=4$ periyotlu birim darbe katarı girişine verdiği çıkış Fourier serisi katsayılarının ($c_k$) frekans yanıtı ve periyodik konvolüsyon yöntemleriyle çözümü.

Dürtü Yanıtı $h[n] \in \{-1, 1\}$
Frekans Yanıtı $1 - 2j(\sin\omega + \sin 2\omega)$
Temel Periyot $N = 4$ ($\omega_0 = \pi/2$)
Çıkış Katsayıları $c_0=c_2=\frac{1}{4}, c_1=\frac{1-2j}{4}$
🎯

Soru Bizden Ne İstiyor?

Dürtü yanıtı aşağıdaki gibi tanımlanan ayrık zamanlı bir LTI sistem verilmiştir:

$$h[n] = \begin{cases} 1, & 0 \le n \le 2 \\ -1, & -2 \le n \le -1 \\ 0, & \text{diğer durumlarda} \end{cases}$$

Sistemin girişi $x[n] = \sum_{k=-\infty}^\infty \delta[n - 4k]$ olduğuna göre, çıkış $y[n]$ sinyalinin Fourier serisi katsayılarını ($c_k$) belirleyiniz.

Çift Doğrulama Avantajı: Bu problem iki bağımsız yoldan çözülebilir: (1) $H(e^{j\omega})$ frekans yanıtını bulup $c_k = a_k H(e^{jk\pi/2})$ çarpmak; (2) Zaman düzleminde periyodik konvolüsyon $y[n] = x[n] * h[n]$ alarak çıkan $[1, 1, 0, -1]$ periyodunun DTFS analizini yapmak!
💡

Adım Adım Çözüm Metodolojisi

  1. Dürtü Yanıtı Örnekleri: $h[-2]=-1, h[-1]=-1, h[0]=1, h[1]=1, h[2]=1$ dizisini belirleme.
  2. Frekans Yanıtı $H(e^{j\omega})$: $H(e^{j\omega}) = 1 + (e^{-j\omega}-e^{j\omega}) + (e^{-j2\omega}-e^{j2\omega}) = 1 - 2j\sin\omega - 2j\sin(2\omega)$ formülünü türetme.
  3. Giriş Katsayıları: $N = 4 \implies a_k = 1/4$ (tüm $k$ için eşit).
  4. Frekans Düzlemi Hesabı: $k = 0, 1, 2, 3$ frekansları ($\omega = 0, \pi/2, \pi, 3\pi/2$) için $H$ değerlerini hesaplayıp $c_k = \frac{1}{4}H$ bulma.
  5. Zaman Düzlemi Konvolüsyonu: $y[n] = \sum_m h[n - 4m]$ ile $y[0]=1, y[1]=1, y[2]=0, y[3]=-1$ dizisini doğrulama.
Nihai Katsayılar: $c_0 = 1/4, \ c_1 = \frac{1-2j}{4}, \ c_2 = 1/4, \ c_3 = \frac{1+2j}{4}$

1

Sonlu Dürtü Yanıtı $h[n]$ ve Simetri Özellikleri

FIR Tanımı

Sistemin dürtü yanıtı 5 ayrık örnekten oluşur:

$$h[-2] = -1, \quad h[-1] = -1, \quad h[0] = 1, \quad h[1] = 1, \quad h[2] = 1$$

Sistem sonlu uzunlukta (FIR) olduğu için her zaman kararlıdır ($\sum |h[n]| = 5 < \infty$). $n < 0$ için sıfır olmadığından nedensel değildir.

2

Frekans Yanıtı $H(e^{j\omega})$ Fonksiyonunun Türetilmesi

Transfer Fonksiyonu

Ayrık zamanlı Fourier dönüşümü formülünü $h[n]$ için yazıp simetrik terimleri eşleştirelim:

$$H(e^{j\omega}) = \sum_{n=-2}^2 h[n] e^{-j\omega n} = -e^{j2\omega} - e^{j\omega} + 1 + e^{-j\omega} + e^{-j2\omega}$$

$$H(e^{j\omega}) = 1 + (e^{-j\omega} - e^{j\omega}) + (e^{-j2\omega} - e^{j2\omega})$$

$$H(e^{j\omega}) = 1 - 2j\sin\omega - 2j\sin(2\omega)$$

Reel kısmı her zaman $1$, sanal kısmı ise $-2(\sin\omega + \sin 2\omega)$ olan karmaşık bir frekans yanıtıdır.

3

Giriş Sinyali $x[n]$ ve DTFS Katsayıları $a_k$

Giriş Spektrumu

Giriş $x[n] = \sum_{k=-\infty}^\infty \delta[n - 4k]$ sinyali $N = 4$ periyotludur. Temel periyodunda tek bir örnek $x[0] = 1$ vardır:

$$a_k = \frac{1}{N}\sum_{n=0}^{N-1} x[n] e^{-jk(2\pi/N)n} = \frac{1}{4} \cdot x[0] = \frac{1}{4}, \quad \forall k$$

Temel açısal frekans $\omega_0 = \frac{2\pi}{4} = \frac{\pi}{2}$ rad/örnektir.

4

Frekans Düzleminde $c_k = a_k H(e^{j k \pi / 2})$ Hesabı

Çıkış Katsayıları

$k = 0, 1, 2, 3$ harmonik frekansları için $H(e^{jk\pi/2})$ değerlerini hesaplayalım:

• $k=0$ ($\omega = 0$): $H(e^{j0}) = 1 - 2j(0 + 0) = 1 \implies c_0 = \frac{1}{4} \cdot 1 = \frac{1}{4} = 0.25$

• $k=1$ ($\omega = \pi/2$): $\sin(\pi/2)=1, \sin(\pi)=0 \implies H(e^{j\pi/2}) = 1 - 2j(1+0) = 1 - 2j$

$$c_1 = a_1 H(e^{j\pi/2}) = \frac{1 - 2j}{4} = 0.25 - 0.5j$$

• $k=2$ ($\omega = \pi$): $\sin(\pi)=0, \sin(2\pi)=0 \implies H(e^{j\pi}) = 1 \implies c_2 = \frac{1}{4} = 0.25$

• $k=3$ ($\omega = 3\pi/2$): $\sin(3\pi/2)=-1, \sin(3\pi)=0 \implies H(e^{j3\pi/2}) = 1 + 2j$

$$c_3 = a_3 H(e^{j3\pi/2}) = \frac{1 + 2j}{4} = 0.25 + 0.5j = c_1^*$$

5

Zaman Düzleminde Periyodik Konvolüsyon ile Doğrulama

Çapraz Sağlama

Çıkış sinyali $y[n] = x[n] * h[n] = \sum_{m=-\infty}^\infty h[n - 4m]$ bağıntısı ile tek bir periyotta doğrudan toplanabilir:

• $n=0: \quad y[0] = h[0] + h[-4] + \dots = 1 + 0 = 1$

• $n=1: \quad y[1] = h[1] + h[-3] + \dots = 1 + 0 = 1$

• $n=2: \quad y[2] = h[2] + h[-2] = 1 + (-1) = 0$ (Kritik Çakışma!)

• $n=3: \quad y[3] = h[3] + h[-1] = 0 + (-1) = -1$

Tek periyot $y[n] = [1, 1, 0, -1]$ olarak bulunur. Buradan analiz formülü: $c_0 = (1+1+0-1)/4 = 1/4$, $c_1 = (1 - j + 0 - (-1)(-j))/4 = (1-2j)/4$, $c_2 = 1/4$, $c_3 = (1+2j)/4$. Birebir örtüşme sağlanır!

6

Eşlenik Simetrisi ve Parseval Enerji Dengesi

Fiziksel Yorum

$y[n]$ gerçel bir sinyal olduğu için $c_{-k} = c_k^*$ olmalıdır. $N = 4$ periyotlu sistemde $c_{-1} = c_3$:

$$c_3 = \frac{1 + 2j}{4} = \left(\frac{1 - 2j}{4}\right)^* = c_1^*$$

Parseval teoremine göre spektral ortalama güç: $$P_{avg} = \sum_{k=0}^3 |c_k|^2 = \left(\frac{1}{4}\right)^2 + \frac{1^2 + (-2)^2}{16} + \left(\frac{1}{4}\right)^2 + \frac{1^2 + 2^2}{16} = \frac{1 + 5 + 1 + 5}{16} = \frac{12}{16} = 0.75$$ Zaman düzleminde ortalama güç: $\frac{1}{4}(1^2 + 1^2 + 0^2 + (-1)^2) = \frac{3}{4} = 0.75$. Enerji tam olarak korunmaktadır!

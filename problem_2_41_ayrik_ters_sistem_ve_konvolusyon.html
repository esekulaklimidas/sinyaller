Problem 2.41 Soru Metni (Oppenheim & Willsky, Sh. 179)

Aşağıdaki ayrık zamanlı işareti ele alınız: $$x[n] = \alpha^n u[n]$$

(a) $g[n] = x[n] - \alpha x[n-1]$ işaretini çiziniz ve kapalı formda ifade ediniz.

(b) (a) şıkkında elde ettiğiniz sonucu konvolüsyonun birleşme ve değişme özellikleri ile birlikte kullanarak, aşağıdaki bağıntıyı sağlayan bir $h[n]$ dizisi belirleyiniz: $$x[n] * h[n] = \left(\frac{1}{2}\right)^n \{u[n+2] - u[n-2]\}$$

İnteraktif Sentez Simülatörü

Ayrık Zaman Stem Çizgeleri & Canlı Doğrulama

$\alpha$ parametresini değiştirerek $g[n] = \delta[n]$ tersliğini ve oluşan $h[n]$ katsayılarını dinamik olarak inceleyin.

Parametre Değeri: α = 0.50 Özel İptal Durumu (2-Tap)
α = -0.9 α = 0.0 α = 0.5 (Özel) α = 0.9
(a) Ters Sistem: $g[n] = x[n] - \alpha x[n-1]$ g[n] = δ[n] (Her α için!)
g[0] = 1, g[n≠0] = 0 İdeal Dirac Darbesi Üretildi
(b) Sentezlenen Filtre: $h[n] = y[n] - \alpha y[n-1]$ h[n] katsayıları
[-2..2]: 4, 0, 0, 0, -0.25 5-Elemanlı FIR Dizi
Canlı Doğrulama: $x[n] * h[n]$ Konvolüsyon Çıkışı vs. Hedef $y[n]$ Maksimum Hata = 0.0000 (%100 Özdeş)
Konvolüsyon Sonucu $x[n]*h[n]$ Hedef $y[n] = (1/2)^n\{u[n+2]-u[n-2]\}$
Tüm n değerlerinde tam örtüşme
(a) Şıkkı Analizi Ters Filtre İspatı

$g[n] = x[n] - \alpha x[n-1]$ İşaretinin Belirlenmesi

Verilen işaret $x[n] = \alpha^n u[n]$'dir. Gecikmiş işaret ise $x[n-1] = \alpha^{n-1} u[n-1]$ olur. $g[n]$ ifadesini $n$'in farklı bölgelerinde adım adım hesaplayalım:

  • $n < 0$ İçin:
    $u[n] = 0$ ve $u[n-1] = 0$ olduğundan: $$g[n] = 0 - \alpha \cdot 0 = 0$$
  • $n = 0$ İçin:
    $x[0] = \alpha^0 u[0] = 1$ ve $x[-1] = \alpha^{-1} u[-1] = 0$: $$g[0] = 1 - \alpha \cdot 0 = 1$$
  • $n \ge 1$ İçin:
    $x[n] = \alpha^n$ ve $x[n-1] = \alpha^{n-1}$: $$g[n] = \alpha^n - \alpha \cdot \left(\alpha^{n-1}\right) = \alpha^n - \alpha^n = 0$$
Sonuç (Kronecker Delta):
$$g[n] = \delta[n]$$
Sistem Kuramı Yorumu: $f[n] = \delta[n] - \alpha \delta[n-1]$ dürtü yanıtına sahip bir filtre, $x[n] = \alpha^n u[n]$ işaretinin tam ters filtresidir (inverse system): $$x[n] * (\delta[n] - \alpha \delta[n-1]) = \delta[n]$$
(b) Şıkkı Analizi $h[n]$ Sentezi

Konvolüsyon Özellikleri ile $h[n]$ Tasarımı

Hedeflenen çıkışa $y[n]$ diyelim: $x[n] * h[n] = y[n] = (1/2)^n \{u[n+2] - u[n-2]\}$. Her iki tarafı $(\delta[n] - \alpha \delta[n-1])$ ile konvolüsyona sokalım:

Birleşme ve Değişme Özelliklerinin Uygulanması:
$$(\delta[n] - \alpha \delta[n-1]) * (x[n] * h[n]) = (\delta[n] - \alpha \delta[n-1]) * y[n]$$ $$[(\delta[n] - \alpha \delta[n-1]) * x[n]] * h[n] = y[n] - \alpha y[n-1]$$
(a) Şıkkındaki $g[n] = \delta[n]$ Bağıntısının Yerine Konması:
$$\delta[n] * h[n] = y[n] - \alpha y[n-1]$$ $$\mathbf{h[n] = y[n] - \alpha y[n-1]}$$
Genel $\alpha$ İçin Kapalı Form Çözüm:
$$h[n] = 4\delta[n+2] + (2-4\alpha)\delta[n+1] + (1-2\alpha)\delta[n] + \left(\frac{1}{2}-\alpha\right)\delta[n-1] - \frac{1}{2}\alpha\delta[n-2]$$
Özel Durum ($\alpha = 1/2$): Ara katsayıların tümü sıfırlanır ($2-4(0.5)=0, 1-2(0.5)=0, 0.5-0.5=0$): $$\mathbf{h[n] = 4\delta[n+2] - \frac{1}{4}\delta[n-2]}$$

İndis Bazında $y[n]$, $y[n-1]$ ve $h[n]$ Ayrık Değerleri

İndis ($n$) Hedef $y[n]$ Gecikmiş $y[n-1]$ Genel Formül: $h[n] = y[n] - \alpha y[n-1]$ Özel Durum ($\alpha = 1/2$)
n = -2 4 0 4 4
n = -1 2 4 2 - 4\alpha 0
n = 0 1 2 1 - 2\alpha 0
n = 1 1/2 = 0.5 1 1/2 - \alpha 0
n = 2 0 1/2 = 0.5 -\alpha/2 -1/4 = -0.25
n diğerleri 0 0 0 0
Filtre Özellikleri: $h[n]$ dizisi $n=-2$ ve $n=-1$ için sıfırdan farklı değer aldığından nedensel değildir (non-causal). Ancak sonlu uzunlukta (FIR) olduğu için $\sum_{-\infty}^\infty |h[n]| = 4 + |2-4\alpha| + |1-2\alpha| + |0.5-\alpha| + 0.5|\alpha| < \infty$ olup kesinlikle BIBO kararlıdır.

Problem 2.61 Soru Metni (Oppenheim & Willsky, Sh. 194-195)
Kısım (a) — LC Devresi

Giriş $x(t)$, çıkış kondansatör gerilimi $y(t)$. $L = 1\text{ H}, C = 1\text{ F}$.

Diferansiyel denklemi, homojen çözümü $K_1 e^{j\omega_1 t} + K_2 e^{j\omega_2 t}$ ve gerilimin reel olmasından ötürü saf sinüzoidal osilasyon olduğunu gösteriniz.

Kısım (b) — RC Devresi

Giriş $x(t)$, çıkış kondansatör gerilimi $y(t)$. $R = 1\,\Omega, C = 1\text{ F}$.

Diferansiyel denklemi belirleyiniz. Doğal yanıtın $K e^{-at}$ biçiminde olduğunu gösterip $a$ değerini bulunuz.

Kısım (c) — RLC Devresi

Giriş $x(t)$, çıkış $y(t)$. $R = 2\,\Omega, L = 1\text{ H}, C = \frac{1}{5}\text{ F}$.

Diferansiyel denklemi bulunuz. Homojen çözümün $e^{-at}\{K_1 e^{j2t} + K_2 e^{-j2t}\}$ ve üstel sönümlü sinüzoyit olduğunu gösteriniz.

Farklı devre tipleri arasında geçiş yaparak osilasyon, sönümleme ve enerji salınımını canlı gözlemleyin.

LC Devresi • Saf Reaktif Osilasyon

d²y/dt² + y(t) = x(t)

Direnç yok ($R=0$). Enerji bobin ile kondansatör arasında sonsuza dek salınır.

Karakteristik Kökler (Kutuplar) s₁,₂ = ± j1.00 Marjinal Kararlı • Saf Sinüs
Kompleks s-Düzlemi ($s = \sigma + j\omega$) Kutuplar (×)
Reel Eksen ($\sigma$) İmajiner Eksen ($j\omega$)
Doğal Yanıt Dalga Biçimi $y_h(t)$ ($y(0)=1\text{V}, y'(0)=0$) y_h(t) = \cos(t)
Gerilim $y_h(t)$ Üstel Zarf $\pm e^{-at}$
t ∈ [0, 10] saniye
(a) LC Devresi Sönümsüz Osilatör

1. KVL ve Diferansiyel Denklem

Devrede $v_L(t) + v_C(t) = x(t)$'dir. Kondansatör akımı $i(t) = C \frac{dy}{dt}$ olup bobinden geçen akımla aynıdır: $$v_L(t) = L \frac{di}{dt} = LC \frac{d^2 y}{dt^2}$$ $L=1\text{ H}, C=1\text{ F} \implies LC = 1$: $$\mathbf{\frac{d^2 y(t)}{dt^2} + y(t) = x(t)}$$

2. Karakteristik Kökler

$s^2 + 1 = 0 \implies s_{1,2} = \pm j1$.
Homojen çözüm: $$y_h(t) = K_1 e^{j1 t} + K_2 e^{-j1 t}$$ Burada $\mathbf{\omega_1 = 1}$ ve $\mathbf{\omega_2 = -1}$'dir.

Reel Fonksiyon Kısıtı: $y(t) \in \mathbb{R} \implies K_2 = K_1^*$.
Kutup koordinatlarında $K_1 = \frac{A}{2}e^{j\phi}$ yazarsak: $$\mathbf{y_h(t) = A \cos(t + \phi)}$$ Sistem saf bir sinüzoidal osilatördür.
(b) RC Devresi 1. Derece Alçak Geçiren

1. KVL ve Diferansiyel Denklem

Devrede $v_R(t) + v_C(t) = x(t)$'dir. $i(t) = C \frac{dy}{dt}$ olduğundan: $$v_R(t) = R \cdot i(t) = RC \frac{dy}{dt}$$ $R=1\,\Omega, C=1\text{ F} \implies RC = 1$: $$\mathbf{\frac{dy(t)}{dt} + y(t) = x(t)}$$

2. Doğal Yanıt Analizi

Homojen denklem: $\frac{dy}{dt} + y = 0 \implies s + 1 = 0 \implies s = -1$. Doğal yanıt: $$y_h(t) = K e^{-at}$$ Burada $\mathbf{a = 1}$'dir.

Fiziksel Anlamı: Sistemde bobin bulunmadığından rezonans veya osilasyon oluşamaz. Direnç enerjiyi ısıya dönüştürür; gerilim monotonik üstel olarak sönümlenir.
(c) RLC Devresi Sönümlü Osilatör

1. KVL ve Diferansiyel Denklem

$v_R(t) + v_L(t) + v_C(t) = x(t)$ eşitliğinde $i = C \frac{dy}{dt}$ yazılır: $$LC \frac{d^2 y}{dt^2} + RC \frac{dy}{dt} + y = x(t)$$ $L=1, R=2, C=1/5 \implies LC=1/5, RC=2/5$: $$\frac{1}{5}\frac{d^2 y}{dt^2} + \frac{2}{5}\frac{dy}{dt} + y = x(t)$$ 5 ile çarparsak: $$\mathbf{\frac{d^2 y(t)}{dt^2} + 2\frac{dy(t)}{dt} + 5y(t) = 5x(t)}$$

2. Karakteristik Kökler

$s^2 + 2s + 5 = 0 \implies s = \frac{-2 \pm \sqrt{4-20}}{2} = -1 \pm j2$.
Homojen çözüm: $$y_h(t) = e^{-at} \{ K_1 e^{j2t} + K_2 e^{-j2t} \}$$ Burada $\mathbf{a = 1}$'dir.

Sönümlü Sinüs: $K_2 = K_1^*$ şartı ile: $$\mathbf{y_h(t) = A e^{-t} \cos(2t + \phi)}$$ Osilasyon frekansı $\omega_d = 2\text{ rad/s}$ olup $e^{-t}$ üstel zarfı altında sönümlenir.

Ayrık Zaman LTI Frekans Yanıtı $H(e^{j\omega})$ Dürtü Katarı Girişi ($N = 4$)

Problem 3.14: Dürtü Katarı Yanıtından $H(e^{jk\pi/2})$ Değerlerinin Belirlenmesi

$x[n] = \sum \delta[n-4k]$ periyodik darbe katarı uygulandığında $y[n] = \cos(\frac{5\pi}{2}n + \frac{\pi}{4})$ çıkışı veren LTI sistemin $k = 0, 1, 2, 3$ için $H(e^{jk\pi/2})$ frekans yanıtı değerlerinin analitik hesabı.

Bulunan Frekans Yanıtı Değerleri:
k = 0$$H(1) = 0$$
k = 1$$2e^{j\pi/4} = \sqrt{2} + j\sqrt{2}$$
k = 2$$H(-1) = 0$$
k = 3$$2e^{-j\pi/4} = \sqrt{2} - j\sqrt{2}$$
🎯

Soru Bizden Ne İstiyor?

  • Girdi: Her 4 örnekte bir 1 olan darbe katarı ($N=4, a_k = 1/4$).
  • Çıkış: $y[n] = \cos(\frac{5\pi}{2}n + \frac{\pi}{4}) = \cos(\frac{\pi}{2}n + \frac{\pi}{4})$.
  • İstenen: $H(e^{jk\pi/2})$ değerleri ($k = 0, 1, 2, 3$).
  • Temel LTI Kuralı: Periyodik girişe sahip LTI sistemde çıkış katsayıları $b_k = a_k H(e^{jk\omega_0})$ olur. Dolayısıyla $H(e^{jk\pi/2}) = b_k / a_k = 4 b_k$.
💡

Adım Adım Çözüm Metodolojisi

  1. Giriş Katsayıları: $a_k = \frac{1}{4}\sum_{n=0}^3 \delta[n]e^{-jk\pi/2 n} = \frac{1}{4}$ ($\forall k$).
  2. Çıkış Frekans İndirgemesi: $\frac{5\pi}{2} = 2\pi + \frac{\pi}{2} \implies y[n] = \cos(\frac{\pi}{2}n + \frac{\pi}{4})$.
  3. Çıkış DTFS Katsayıları: $b_1 = \frac{1}{2}e^{j\pi/4}$, $b_3 = b_{-1} = \frac{1}{2}e^{-j\pi/4}$, $b_0 = b_2 = 0$.
  4. Frekans Yanıtı Eşitliği: $H(e^{jk\pi/2}) = 4 b_k$.
  5. Sayısal Değerler: $H(e^0)=0, H(e^{j\pi/2})=2e^{j\pi/4}, H(e^{j\pi})=0, H(e^{j3\pi/2})=2e^{-j\pi/4}$.

Canlı Simülatör: DT LTI Frekans Yanıtı Fazörleri ve Çıkış Sentezi

Harmonik indeksini seçerek karmaşık düzlemde $H(e^{jk\pi/2})$ fazörünü ve $y[n]$ dalga şeklini görüntüleyin.

Harmonik İndeksi ($k$): k = 1
Filtre Faz Kayması: +π/4 (+45°)
$$H(e^{j\pi/2}) = 2 e^{j\pi/4} = \sqrt{2} + j\sqrt{2}$$
Karmaşık Düzlem: $H(e^{jk\pi/2})$ Değerleri ($k = 0, 1, 2, 3$) Kutup/Sıfır Kazanç Noktaları
Ayrık Zaman Domeni: Giriş $x[n]$ (Darbe Katarı) vs Çıkış $y[n] = \cos(\frac{\pi}{2}n + \frac{\pi}{4})$ N = 4 Periyot
Hesaplanıyor...
1. Adım

Giriş Dürtü Katarının DTFS Katsayıları

$x[n] = \sum_{k=-\infty}^{\infty} \delta[n - 4k]$ sinyali $N = 4$ periyotludur. Temel periyot içinde tek bir darbe vardır ($x[0] = 1, x[1]=x[2]=x[3]=0$): $$a_k = \frac{1}{4} \sum_{n=0}^3 x[n] e^{-jk\frac{\pi}{2}n} = \frac{1}{4} \cdot 1 \cdot e^0 = \mathbf{\frac{1}{4}} \quad (\forall k \in \mathbb{Z})$$

2. Adım

Çıkış Sinyalinin Frekans İndirgemesi

Çıkış formülünde $\frac{5\pi}{2} n$ açısı yer almaktadır: $$\frac{5\pi}{2} n = \left(2\pi + \frac{\pi}{2}\right) n = 2\pi n + \frac{\pi}{2} n$$ Ayrık zamanda $2\pi n$ periyodikliği nedeniyle: $$y[n] = \cos\left(\frac{5\pi}{2} n + \frac{\pi}{4}\right) = \mathbf{\cos\left(\frac{\pi}{2} n + \frac{\pi}{4}\right)}$$

3. Adım

Çıkış Sinyalinin DTFS Katsayıları $b_k$

Euler bağıntısıyla $y[n]$'i üstel bileşenlerine ayıralım: $$y[n] = \frac{1}{2} e^{j\pi/4} e^{j\frac{\pi}{2}n} + \frac{1}{2} e^{-j\pi/4} e^{-j\frac{\pi}{2}n}$$ Burada $e^{-j\frac{\pi}{2}n} = e^{j\frac{3\pi}{2}n}$ olduğundan: $$b_1 = \frac{1}{2} e^{j\pi/4}, \quad b_3 = \frac{1}{2} e^{-j\pi/4}, \quad b_0 = 0, \quad b_2 = 0$$

4. Adım

LTI Filtreleme Bağıntısı $b_k = a_k H(e^{jk\omega_0})$

LTI sistem özellikleri uyarınca: $$b_k = a_k H\left(e^{jk\frac{\pi}{2}}\right) \implies H\left(e^{jk\frac{\pi}{2}}\right) = \frac{b_k}{a_k}$$ $a_k = 1/4$ olduğundan: $$\mathbf{H\left(e^{jk\frac{\pi}{2}}\right) = 4 b_k}$$

5. Adım

4 Frekans Yanıtı Değerinin Hesaplanması

  • k = 0: $H(e^{j0}) = 4 b_0 = 4(0) = \mathbf{0}$
  • k = 1: $H(e^{j\pi/2}) = 4 b_1 = 4 \left(\frac{1}{2} e^{j\pi/4}\right) = 2 e^{j\pi/4} = \mathbf{\sqrt{2} + j\sqrt{2}}$
  • k = 2: $H(e^{j\pi}) = 4 b_2 = 4(0) = \mathbf{0}$
  • k = 3: $H(e^{j3\pi/2}) = 4 b_3 = 4 \left(\frac{1}{2} e^{-j\pi/4}\right) = 2 e^{-j\pi/4} = \mathbf{\sqrt{2} - j\sqrt{2}}$

6. Adım

Mühendislik Yorumu ve Sınav Tablosu

Sistem, giriş dürtü katarındaki $\omega = 0$ ve $\omega = \pi$ bileşenlerini tamamen sıfırlayan, yalnızca $\omega = \pm \pi/2$ temel harmoniklerini $2$ kazancı ve $\pm \pi/4$ faz kaymasıyla geçiren bir ayrık zaman bant geçiren filtre gibi davranmaktadır.

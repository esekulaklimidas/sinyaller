Problem 3.28: Periyodik Ayrık Zaman Sinyalleri İçin DTFS Katsayıları, Genlik ve Faz Çizimi

Şekil P3.28(a)-(c)'de verilen dalga şekilleri ile trigonometrik çarpım ve sinüs tabanlı ayrık zaman periyodik sinyallerinin Fourier serisi katsayıları $a_k$'nın analitik olarak hesaplanması, $|a_k|$ genlik ve $\angle a_k$ faz spektrumlarının çizilmesi.

Analiz Denklemi: $a_k = \frac{1}{N} \sum_{n=\langle N \rangle} x[n] e^{-j k \frac{2\pi}{N} n}$
Kapsam: (a) Şekil P3.28 (a, b, c), (b) $\sin(2\pi n/3)\cos(\pi n/2)$, (c) $N=4$ sinüs, (d) $N=12$ sinüs
Spektrum Temsili: Ayrık genlik $|a_k|$ ve faz $\angle a_k$ stem grafikleri ($N$-periyodik)

💡 Sonlu Geometrik Dizi & Modulo N

Ayrık dikdörtgen darbeler için Fourier toplamı sonlu geometrik dizi toplamıdır:

\sum_{n=0}^{M-1} e^{-j\omega n} = \frac{1 - e^{-j\omega M}}{1 - e^{-j\omega}} = e^{-j\omega \frac{M-1}{2}} \frac{\sin(\omega M / 2)}{\sin(\omega / 2)}

Bu orantı, ayrık zaman frekans spektrumunda Dirichlet / periyodik sinc çekirdeğini üretir.

1

Şekil P3.28(a): N = 7 Dikdörtgensel Darbe Katarı

Şekil (a)

Şekil P3.28(a)'da temel periyot $N = 7$'dir. Bir periyotta $n = 0, 1, 2, 3, 4$ için $x[n] = 1$ ve $n = 5, 6$ için $x[n] = 0$'dır. DTFS analiz formülü:

$$a_k = \frac{1}{7} \sum_{n=0}^{4} e^{-j k \frac{2\pi}{7} n}$$

Sonlu geometrik dizi toplam formülü uygulanırsa:

$$a_k = \frac{1}{7} \frac{1 - e^{-j 10\pi k / 7}}{1 - e^{-j 2\pi k / 7}} = \frac{1}{7} e^{-j 4\pi k / 7} \frac{\sin(5\pi k / 7)}{\sin(\pi k / 7)} \quad (k \ne 0)$$

$k = 0$ için $a_0 = \frac{5}{7}$. Genlik $|a_k| = \frac{1}{7} \left| \frac{\sin(5\pi k / 7)}{\sin(\pi k / 7)} \right|$ ve faz simetriden kaynaklanan doğrusal faz terimidir.

2

Şekil P3.28(b): N = 6 Dikdörtgensel Darbe Katarı

Şekil (b)

Şekil P3.28(b)'de temel periyot $N = 6$'dır. $n = 0, 1, 2, 3$ için $x[n] = 1$ ve $n = 4, 5$ için $x[n] = 0$'dır:

$$a_k = \frac{1}{6} \sum_{n=0}^{3} e^{-j k \frac{2\pi}{6} n} = \frac{1}{6} \frac{1 - e^{-j 4\pi k / 3}}{1 - e^{-j \pi k / 3}}$$

Üstel terimler paranteze alınarak sinüs oranına dönüştürülürse:

$$a_k = \frac{1}{6} e^{-j \pi k / 2} \frac{\sin(2\pi k / 3)}{\sin(\pi k / 3)} \quad (k \ne 0)$$

$k=0$ için $a_0 = \frac{4}{6} = \frac{2}{3}$. Diğer katsayılar: $a_1 = \frac{1}{6} e^{-j\pi/2} = -j\frac{1}{6}$, $a_2 = 0$, $a_3 = 0$, $a_4 = 0$, $a_5 = j\frac{1}{6}$.

3

Şekil P3.28(c): N = 6 Basamaklı Ayrık Sinyal

Şekil (c)

Şekil P3.28(c)'de $N = 6$ olup periyot içindeki değerler şöyledir: $$x[0] = 2, \quad x[1] = 1, \quad x[2] = 0, \quad x[3] = -1, \quad x[4] = -1, \quad x[5] = 0$$

DTFS analiz toplamı doğrudan açılır:

$$a_k = \frac{1}{6} \left[ 2 + e^{-j \pi k / 3} - e^{-j \pi k} - e^{-j 4\pi k / 3} \right]$$

$a_0 = \frac{2 + 1 + 0 - 1 - 1 + 0}{6} = \frac{1}{6}$. $k = 1, 2, 3, 4, 5$ değerleri hesaplanarak genlik $|a_k|$ ve faz $\angle a_k$ elde edilir.

4

b Şıkkı: x[n] = sin(2πn/3)cos(πn/2) Çarpımı

b Şıkkı Çözümü

Trigonometrik çarpımı toplama dönüştürelim: $$\sin(A)\cos(B) = \frac{1}{2}\left[\sin(A+B) + \sin(A-B)\right]$$ $$A = \frac{2\pi n}{3} = \frac{4\pi n}{6}, \quad B = \frac{\pi n}{2} = \frac{3\pi n}{6}$$

$$x[n] = \frac{1}{2}\sin\left(\frac{7\pi n}{6}\right) + \frac{1}{2}\sin\left(\frac{\pi n}{6}\right)$$

Temel frekans $\omega_0 = \frac{\pi}{6}$ ve temel periyot $N = \frac{2\pi}{\pi/6} = 12$'dir. Euler formülü ile $k = 1, 5, 7, 11$ harmonikleri bulunur:

$$a_1 = -\frac{j}{4}, \quad a_5 = \frac{j}{4}, \quad a_7 = -\frac{j}{4}, \quad a_{11} = \frac{j}{4}, \quad a_k = 0 \text{ (diğerleri)}$$
5

c Şıkkı: N = 4 Periyotlu x[n] = 1 - sin(πn/4)

c Şıkkı Çözümü

$N = 4$ için $0 \le n \le 3$ örneklerini hesaplayalım: $$x[0] = 1 - \sin(0) = 1$$ $$x[1] = 1 - \sin(\pi/4) = 1 - \frac{\sqrt{2}}{2} \approx 0.293$$ $$x[2] = 1 - \sin(\pi/2) = 1 - 1 = 0$$ $$x[3] = 1 - \sin(3\pi/4) = 1 - \frac{\sqrt{2}}{2} \approx 0.293$$

DTFS analiz toplamı $a_k = \frac{1}{4} \sum_{n=0}^3 x[n] e^{-j k \frac{\pi}{2} n}$ formülünden:

$$a_0 = \frac{1 + (1-\sqrt{2}/2) + 0 + (1-\sqrt{2}/2)}{4} = \frac{3 - \sqrt{2}}{4} \approx 0.396$$ $$a_1 = a_3^* = \frac{1 - j(1-\sqrt{2}/2) - (0) + j(1-\sqrt{2}/2)}{4} = \frac{1}{4}$$ $$a_2 = \frac{1 - (1-\sqrt{2}/2) + 0 - (1-\sqrt{2}/2)}{4} = \frac{\sqrt{2} - 1}{4} \approx 0.104$$
6

d Şıkkı: N = 12 Periyotlu x[n] = 1 - sin(πn/4)

d Şıkkı Çözümü

$N = 12$ olduğunda temel açısal frekans $\omega_0 = \frac{2\pi}{12} = \frac{\pi}{6}$'dır. İçerideki sinüs teriminin frekansı $\frac{\pi}{4} = 3 \cdot \frac{\pi}{6} = 3\omega_0$'dır!

$$x[n] = 1 - \sin(3\omega_0 n) = 1 - \left[\frac{e^{j3\omega_0 n} - e^{-j3\omega_0 n}}{2j}\right] = 1 + \frac{j}{2} e^{j3\omega_0 n} - \frac{j}{2} e^{-j3\omega_0 n}$$

$-3 \equiv 9 \pmod{12}$ olduğundan katsayılar doğrudan terim eşleştirmesi ile bulunur:

$$a_0 = 1, \quad a_3 = -\frac{1}{2j} = \frac{j}{2}, \quad a_9 = \frac{1}{2j} = -\frac{j}{2}, \quad a_k = 0 \text{ (diğer tüm } k \in [0, 11]\text{)}$$

Genlikler: $|a_0| = 1$, $|a_3| = 0.5$, $|a_9| = 0.5$. Fazlar: $\angle a_0 = 0$, $\angle a_3 = +\pi/2$, $\angle a_9 = -\pi/2$.

Sınav Sorusu 3: LTI İntegral Bağıntısı, Dürtü Yanıtı ve LTI Özellikleri

Giriş-çıkış ilişkisi $y(t) = \int_{-\infty}^{t} e^{-(t - \tau)} x(\tau - 2) d\tau$ olan sürekli zamanlı bir LTI sistemin analizi; Dirac delta ile birim dürtü yanıtı $h(t)$'nin bulunması, parçalı kutu darbe yanıtının entegrasyonu ve LTI doğrusallık / zamanla değişmezlik özellikleri kullanılarak konvolüsyonsuz doğrudan çıkış hesabı.

Verilen Sistem Eşitliği:
$$y(t) = \int_{-\infty}^{t} e^{-(t - \tau)} x(\tau - 2) d\tau$$
(a) Dürtü Yanıtı (9p):
$$h(t) = e^{-(t - 2)} u(t - 2)$$
(b) Kutu Yanıtı (9p):
$$y(t) = \begin{cases} 0, & t < 1 \\ 1 - e^{-(t - 1)}, & 1 \le t < 4 \\ (1 - e^{-3}) e^{-(t - 4)}, & t \ge 4 \end{cases}$$
(c) LTI Çıkışı (7p):
$$x_c(t) = 2x(t - 4) \implies y_c(t) = 2y(t - 4)$$

  • (c) Şıkkı (7 Puan): $[3, 6]$ aralığında genliği 2 olan yeni girişin çıktısını konvolüsyon integrali hesaplamadan, yalnızca LTI özelliklerini (Ölçekleme + Zaman Kaydırma) kullanarak doğrudan türetmek.

Adım Adım Çözüm Metodolojisi

1. Süzme ile h(t): $x(\tau - 2) = \delta(\tau - 2)$ yerleştirildiğinde darbe $\tau = 2$'dedir. İntegral üst sınırı $t \ge 2$ olduğunda $\tau = 2$ aralığa girer $\implies h(t) = e^{-(t-2)} u(t-2)$.
2. Değişken Dönüşümü & Parçalı Çözüm: $\lambda = \tau - 2$ dönüşümüyle $y(t) = \int_{-\infty}^{t-2} e^{-(t-2-\lambda)} x(\lambda) d\lambda$. Kutu $[-1, 2]$ aralığında olduğundan $t < 1$, $1 \le t < 4$ ve $t \ge 4$ olarak 3 bölgede çözülür.
3. LTI Dönüşüm Eşleme: $x_c(t)$ kutusu $[-1, 2]$'nin 4 birim sağa kaydırılmış ve 2 ile çarpılmış halidir: $x_c(t) = 2x(t - 4)$. LTI sistemlerde çıkış doğrudan $y_c(t) = 2y(t - 4)$ olur!

Adım 1

Sistem İntegral Eşitliği ve Konvolüsyon Biçimine Dönüştürme

Verilen sistem $y(t) = \int_{-\infty}^{t} e^{-(t - \tau)} x(\tau - 2) d\tau$ bağıntısı ile tanımlanmıştır. Bu ifadenin standart konvolüsyon integrali $y(t) = \int_{-\infty}^{\infty} x(\lambda) h(t - \lambda) d\lambda$ ile ilişkisini görmek için değişken dönüşümü yapalım: $$\lambda = \tau - 2 \implies \tau = \lambda + 2, \quad d\tau = d\lambda$$ Sınırlar: $\tau = -\infty \to \lambda = -\infty$ ve $\tau = t \to \lambda = t - 2$: $$y(t) = \int_{-\infty}^{t - 2} e^{-(t - (\lambda + 2))} x(\lambda) d\lambda = \int_{-\infty}^{t - 2} e^{-(t - 2 - \lambda)} x(\lambda) d\lambda$$ Bu form, sistemin bir standart LTI konvolüsyon operatörü olduğunu açıkça ortaya koyar!

Adım 2

(a) Şıkkı Çözümü — Birim Dürtü Yanıtı $h(t)$'nin Bulunması (9 Puan)

Birim dürtü yanıtı $h(t)$, sisteme $x(t) = \delta(t)$ uygulandığında elde edilen çıkıştır. Girişi denklemde yerine koyalım: $$h(t) = \int_{-\infty}^{t} e^{-(t - \tau)} \delta(\tau - 2) d\tau$$ $\delta(\tau - 2)$ darbesi $\tau = 2$ noktasında yer alır. Süzme (sifting) özelliğine göre: $$\text{Eğer } t < 2 \text{ ise, } \tau = 2 \text{ entegrasyon sınırının dışındadır } \implies h(t) = 0$$ $$\text{Eğer } t \ge 2 \text{ ise, } \tau = 2 \text{ entegrasyon aralığındadır } \implies h(t) = e^{-(t - 2)}$$ Bu iki durumu birim basamak $u(t - 2)$ ile birleştirirsek: $$\mathbf{h(t) = e^{-(t - 2)} u(t - 2)}$$

Adım 3

(b) Şıkkı Çözümü — Dikdörtgen Kutu Girişi Yanıtı $y(t)$ (9 Puan)

Giriş sinyali $x(t) = 1$ ($-1 \le t \le 2$), $0$ (d.y.) olarak verilmiştir ($x(\lambda) = 1, \lambda \in [-1, 2]$).
İntegral formülü: $y(t) = \int_{-\infty}^{t - 2} e^{-(t - 2 - \lambda)} x(\lambda) d\lambda$. Üst sınır $t - 2$'nin konumuna göre 3 bölge incelenir:

  • Bölge 1 ($t - 2 < -1 \iff t < 1$): Örtüşme yoktur: $\mathbf{y(t) = 0}$.
  • Bölge 2 ($-1 \le t - 2 < 2 \iff 1 \le t < 4$): $$y(t) = \int_{-1}^{t - 2} e^{-(t - 2 - \lambda)} d\lambda = e^{-(t - 2)} \left[ e^\lambda \right]_{-1}^{t - 2} = e^{-(t - 2)} (e^{t - 2} - e^{-1}) = \mathbf{1 - e^{-(t - 1)}}$$
  • Bölge 3 ($t - 2 \ge 2 \iff t \ge 4$): Kutu tamamen taranmıştır: $$y(t) = \int_{-1}^{2} e^{-(t - 2 - \lambda)} d\lambda = e^{-(t - 2)} (e^2 - e^{-1}) = (1 - e^{-3}) e^{-(t - 4)}$$
Adım 4

Birim Basamak Yanıtı ile Alternatif Doğrulama

Sistemin birim basamak yanıtı $s(t) = \int_{-\infty}^{t} h(\tau) d\tau = (1 - e^{-(t - 2)}) u(t - 2)$'dir.
Giriş $x(t)$ iki birim basamağın farkı olarak ifade edilebilir: $$x(t) = u(t + 1) - u(t - 2)$$ LTI doğrusallığı ve zamanla değişmezliği gereği sistem çıkışı: $$y(t) = s(t + 1) - s(t - 2)$$ $$y(t) = \left(1 - e^{-(t + 1 - 2)}\right) u(t + 1 - 2) - \left(1 - e^{-(t - 2 - 2)}\right) u(t - 2 - 2)$$ $$\mathbf{y(t) = \left(1 - e^{-(t - 1)}\right) u(t - 1) - \left(1 - e^{-(t - 4)}\right) u(t - 4)}$$ Bu formül Adım 3'teki parçalı sonuçla birebir aynıdır ve sürekliliği garanti eder!

Adım 5

(c) Şıkkı Çözümü — Konvolüsyonsuz LTI Özellikleri (7 Puan)

Soruda açıkça "Do not use direct computation by using convolution integral. You must use only properties of LTI systems" talimatı verilmiştir.
(b)'deki giriş $x(t)$: $[-1, 2]$ aralığında, genlik = $1$.
(c)'deki yeni giriş $x_c(t)$: $[3, 6]$ aralığında, genlik = $2$.
İki sinyal arasındaki matematiksel ilişkiyi kuralım: $$\text{Zaman Kayması: } 3 - (-1) = 4 \implies x(t - 4) \text{ sinyali } [3, 6] \text{ aralığındadır.}$$ $$\text{Genlik Ölçekleme: } 2 \cdot x(t - 4) \implies x_c(t) = 2 x(t - 4)$$ LTI sistem özelliklerini sırayla uygulayalım: $$1.\; \text{Zamanla Değişmezlik: } x(t - 4) \xrightarrow{\text{LTI}} y(t - 4)$$ $$2.\; \text{Homojenlik (Doğrusallık): } 2 x(t - 4) \xrightarrow{\text{LTI}} 2 y(t - 4)$$ Dolayısıyla yeni çıkış doğrudan: $$\mathbf{y_c(t) = 2 y(t - 4) = 2\left(1 - e^{-(t - 5)}\right) u(t - 5) - 2\left(1 - e^{-(t - 8)}\right) u(t - 8)}$$

Problem 3.30: Ayrık Zaman Çarpma Özelliği ve Spektral Periyodik Konvolüsyon

Temel periyodu $N = 6$ olan $x[n] = 1 + \cos(\frac{\pi}{3}n)$ ve $y[n] = \sin(\frac{\pi}{3}n + \frac{\pi}{4})$ sinyallerinin çarpımı olan $z[n] = x[n]y[n]$ dizisinin Fourier katsayılarının DTFS çarpma özelliği (periyodik konvolüsyon) ile hesaplanması ve doğrudan trigonometrik çarpım-toplam özdeşliği ile analitik doğrulanması.

Verilen Sinyaller: $x[n] = 1 + \cos\left(\frac{2\pi}{6}n\right), \quad y[n] = \sin\left(\frac{2\pi}{6}n + \frac{\pi}{4}\right), \quad z[n] = x[n]y[n]$
Temel Frekans: $N = 6, \quad \omega_0 = \frac{2\pi}{6} = \frac{\pi}{3}\text{ rad/örnek}$
Çarpma Özelliği: $z[n] = x[n]y[n] \longleftrightarrow c_k = \sum_{l=\langle N \rangle} a_l b_{k-l} = a_k \circledast b_k$

Soru Analizi & Mini Konu Anlatımı

🎯 Soru Bizden Ne İstiyor?

  • (a) $x[n]$ için DTFS katsayıları $a_k$'nın belirlenmesi.
  • (b) $y[n]$ için DTFS katsayıları $b_k$'nın belirlenmesi.
  • (c) DTFS çarpma özelliği $c_k = \sum_{l=\langle 6 \rangle} a_l b_{k-l}$ ile $z[n]$'in katsayılarının bulunması.
  • (d) $z[n]$ sinyalini trigonometrik özdeşliklerle açarak doğrudan $c_k$'nın bulunması ve (c) ile karşılaştırılması.

💡 DTFS Periyodik Konvolüsyon Kuralı

Ayrık zamanda iki periyodik sinyalin çarpımı, spektrumda döngüsel / periyodik konvolüsyona karşılık gelir:

c_k = \sum_{l=0}^{N-1} a_l b_{(k-l) \pmod N}

Sürekli zamanın aksine, toplam sonsuza gitmez; tam olarak $N$ adet terim üzerinden periyodik modulo aritmetiği ile hesaplanır.

1

x[n] İçin DTFS Katsayıları ak (a Şıkkı)

a Şıkkı

Verilen $x[n] = 1 + \cos(\frac{\pi}{3}n)$ sinyalinin temel periyodu $N = 6$ ve temel frekansı $\omega_0 = \frac{2\pi}{6} = \frac{\pi}{3}$'tür. Euler açılımı:

$$x[n] = 1 + \frac{1}{2} e^{j\frac{\pi}{3}n} + \frac{1}{2} e^{-j\frac{\pi}{3}n} = 1 + \frac{1}{2} e^{j\omega_0 n} + \frac{1}{2} e^{j 5\omega_0 n}$$

$-1 \equiv 5 \pmod 6$ olduğundan katsayılar bir temel periyot ($k \in [0, 5]$) içinde:

$$a_0 = 1, \quad a_1 = \frac{1}{2}, \quad a_5 = \frac{1}{2}, \quad a_2 = a_3 = a_4 = 0$$
2

y[n] İçin DTFS Katsayıları bk (b Şıkkı)

b Şıkkı

$y[n] = \sin(\frac{\pi}{3}n + \frac{\pi}{4})$ sinyalini Euler formülü ile açalım:

$$y[n] = \frac{1}{2j} e^{j(\frac{\pi}{3}n + \frac{\pi}{4})} - \frac{1}{2j} e^{-j(\frac{\pi}{3}n + \frac{\pi}{4})} = \left(\frac{1}{2} e^{-j\frac{\pi}{4}}\right) e^{j\frac{\pi}{3}n} + \left(\frac{1}{2} e^{j\frac{\pi}{4}}\right) e^{-j\frac{\pi}{3}n}$$

Burada $\frac{1}{j} = e^{-j\pi/2}$ özdeşliği kullanılmıştır. Modulo 6 ile $k=5 \equiv -1$ olduğundan:

$$b_1 = \frac{1}{2} e^{-j\pi/4} = \frac{\sqrt{2}}{4}(1 - j), \quad b_5 = \frac{1}{2} e^{j\pi/4} = \frac{\sqrt{2}}{4}(1 + j), \quad b_k = 0 \text{ (diğerleri)}$$
3

DTFS Çarpma Teoremi & Periyodik Konvolüsyon (c Şıkkı)

c Şıkkı Formülasyon

Ayrık zaman Fourier serisi çarpma özelliği Tablo 3.2 uyarınca:

$$z[n] = x[n]y[n] \longleftrightarrow c_k = \sum_{l=\langle 6 \rangle} a_l b_{k-l}$$

$a_l$ katsayıları yalnızca $l = 0, 1, 5$ ($l = 0, \pm 1$) için sıfırdan farklıdır:

$$c_k = a_0 b_k + a_1 b_{k-1} + a_5 b_{k+1} = b_k + \frac{1}{2} b_{k-1} + \frac{1}{2} b_{k+1}$$
4

Tüm ck Katsayılarının Açıkça Hesaplanması

ck Katsayıları

Bulunan formülde $k \in [0, 5]$ değerlerini tek tek yerine yazalım:

  • k = 0: $c_0 = b_0 + \frac{1}{2}b_5 + \frac{1}{2}b_1 = 0 + \frac{1}{4}(e^{j\pi/4} + e^{-j\pi/4}) = \frac{1}{2}\cos(\pi/4) = \frac{\sqrt{2}}{4} \approx 0.354$
  • k = 1: $c_1 = b_1 + \frac{1}{2}b_0 + \frac{1}{2}b_2 = b_1 = \frac{1}{2}e^{-j\pi/4} = \frac{\sqrt{2}}{4}(1 - j)$
  • k = 2: $c_2 = b_2 + \frac{1}{2}b_1 + \frac{1}{2}b_3 = \frac{1}{2}b_1 = \frac{1}{4}e^{-j\pi/4} = \frac{\sqrt{2}}{8}(1 - j)$
  • k = 3: $c_3 = b_3 + \frac{1}{2}b_2 + \frac{1}{2}b_4 = 0$
  • k = 4: $c_4 = c_2^* = \frac{1}{4}e^{j\pi/4} = \frac{\sqrt{2}}{8}(1 + j)$
  • k = 5: $c_5 = c_1^* = \frac{1}{2}e^{j\pi/4} = \frac{\sqrt{2}}{4}(1 + j)$
$$c_0 = \frac{\sqrt{2}}{4}, \quad c_1 = \frac{1}{2}e^{-j\pi/4}, \quad c_2 = \frac{1}{4}e^{-j\pi/4}, \quad c_3 = 0, \quad c_4 = \frac{1}{4}e^{j\pi/4}, \quad c_5 = \frac{1}{2}e^{j\pi/4}$$
5

Trigonometrik Doğrudan Açılım ile Doğrulama (d Şıkkı)

d Şıkkı Doğrulama

$z[n] = x[n]y[n]$ ifadesini parantezleri çarparak doğrudan açalım:

$$z[n] = \sin\left(\frac{\pi}{3}n + \frac{\pi}{4}\right) + \cos\left(\frac{\pi}{3}n\right)\sin\left(\frac{\pi}{3}n + \frac{\pi}{4}\right)$$

$\cos(A)\sin(B) = \frac{1}{2}[\sin(B+A) + \sin(B-A)]$ özdeşliği uygulanırsa:

$$\cos\left(\frac{\pi}{3}n\right)\sin\left(\frac{\pi}{3}n + \frac{\pi}{4}\right) = \frac{1}{2}\sin\left(\frac{2\pi}{3}n + \frac{\pi}{4}\right) + \frac{1}{2}\sin\left(\frac{\pi}{4}\right)$$

Böylece $z[n]$ doğrudan harmonik sinüslerin toplamı olur:

$$z[n] = \frac{\sqrt{2}}{4} + \sin\left(\omega_0 n + \frac{\pi}{4}\right) + \frac{1}{2}\sin\left(2\omega_0 n + \frac{\pi}{4}\right)$$

DC Terim: $c_0 = \frac{\sqrt{2}}{4}$ | 1. Harmonik: $c_1 = \frac{1}{2}e^{-j\pi/4}$ | 2. Harmonik: $c_2 = \frac{1}{4}e^{-j\pi/4}$ (TAM UYUM ✓).

Mühendislik Yorumu ve Sürekli vs Ayrık Zaman Karşılaştırması

Özet & Kıyaslama

Problem 3.25 (Sürekli Zaman) ile Problem 3.30 (Ayrık Zaman) arasındaki temel farklar:

CT Çarpma (Problem 3.25) • Katsayılar sonsuz konvolüsyondur: $c_k = \sum_{-\infty}^\infty a_l b_{k-l}$
• Harmonikler üst sınırsızdır.
DT Çarpma (Problem 3.30) • Katsayılar döngüsel/periyodik konvolüsyondur: $c_k = \sum_{\langle N \rangle} a_l b_{k-l}$
• Yalnızca $N$ adet bağımsız harmonik vardır.

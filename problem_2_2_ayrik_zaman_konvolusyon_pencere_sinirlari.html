Ayrık Zaman (Discrete-Time) Oppenheim Problem 2.2

Problem 2.2 — Kayan Filtre Penceresinin Sınır Analizi ($A \le k \le B$)

$$h[n] = \left( rac{1}{2} ight)^{n-1} ig\{u[n+3] - u[n-10]ig\} \quad \Longrightarrow \quad h[n-k] = \begin{cases} (1/2)^{n-k-1}, & A \le k \le B \ 0, & ext{diğer} \end{cases}$$ Konvolüsyon toplamında filtrenin sıfırdan farklı olduğu $k$ aralığının sınırları: $A = n - 9$ ve $B = n + 3$.

Soru Analizi & Mini Konu Anlatımı

Konvolüsyon çekirdeği $h[n-k]$'nın bağımsız değişken dönüşümü ve sınır tespiti

📌 Soru Bizden Ne İstiyor?

  • Fiziksel Model: $w[n] = u[n+3] - u[n-10]$ sonlu süreli bir dikdörtgen penceredir (13 örnek).
  • İstenen: $h[n-k]$ kayan filtresinin sıfırdan farklı olduğu $A \le k \le B$ sınırlarını $n$ cinsinden belirlemek.
  • Kritik Nokta: Zaman tersleme nedeniyle $h[n]$'nin sol kenarı ($n=-3$), $h[n-k]$'nin sağ kenarına ($k=n+3$) dönüşür.

💡 Adım Adım Çözüm Metodolojisi

  1. Pencere Aralığı: $u[n+3] - u[n-10] = 1 \iff -3 \le n < 10 \iff -3 \le n \le 9$.
  2. Değişken Dönüşümü: $n o n - k \implies -3 \le n - k \le 9$.
  3. Eşitsizliği Çözme: $-3 - n \le -k \le 9 - n \implies n - 9 \le k \le n + 3$.
  4. Sınır Eşleşmesi: $A = n - 9$ ve $B = n + 3$ bulunur.

1. Adım

Birim Basamak Penceresinin Analizi: $u[n+3] - u[n-10]$

$u[n+3] = 1 \iff n \ge -3$ ve $u[n-10] = 1 \iff n \ge 10$'dur. Fark alındığında pencere $n \in [-3, 9]$ arasında 13 tam sayı noktasında 1'dir.

2. Adım

Zaman Tersleme: $h[-k]$

$h[k]$ sinyali $k=0$ eksenine göre katlandığında aktif aralık $[-9, 3]$ olur. En sağdaki ön uç $k=3$'tür.

3. Adım

Eşitsizlik Çözümü: $-3 \le n - k \le 9$

Her taraftan $n$ çıkarılıp $-1$ ile çarpıldığında eşitsizlik yön değiştirir: $$-3 - n \le -k \le 9 - n \implies n - 9 \le k \le n + 3$$

4. Adım

Sınırların Tanımı: $A = n - 9$ ve $B = n + 3$

Sol sınır $A = n - 9$ (arka kenar), sağ sınır $B = n + 3$ (ön kenar). Pencere uzunluğu $(n+3) - (n-9) + 1 = 13$ sabit kalır.

5. Adım

Farklı $n$ Değerleri İçin Pencere Konumları

$n = -5 \implies [-14, -2]$; $n = 0 \implies [-9, 3]$; $n = 5 \implies [-4, 8]$; $n = 10 \implies [1, 13]$.

6. Adım

Nihai Sonuç Özeti

$$h[n-k] = \begin{cases} (1/2)^{n-k-1}, & n - 9 \le k \le n + 3 \ 0, & ext{diğer} \end{cases} \quad \implies \quad \mathbf{A = n - 9, \quad B = n + 3}$$

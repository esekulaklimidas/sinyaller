Ayrık Zaman (Discrete-Time) Oppenheim Problem 3.2

Problem 3.2 — Ayrık Zaman Fourier Serisi (DTFS) ve Trigonometrik Sinüs Gösterimi

$$x[n] \text{ reel ve periyodik}, \quad N = 5, \quad a_0 = 1, \quad a_2 = a_{-2}^* = e^{j\pi/4}, \quad a_4 = a_{-4}^* = 2e^{j\pi/3}$$ $$x[n] = A_0 + \sum_{k=1}^{\infty} A_k \sin(\omega_k n + \phi_k)$$ Ayrık zaman Fourier serisi katsayılarının ($a_k$) periyodikliği, reel sinyallerde eşlenik simetrisi ve Euler bağıntısı kullanılarak sinyal sinüs harmonikleri formunda ifade edilir.

Soru Analizi & Mini Konu Anlatımı

Ayrık zaman Fourier serisi (DTFS), katsayı periyodikliği ve sinüs dönüşüm ilkeleri

🎯 Soru Bizden Ne İstiyor?

  • Fiziksel Model: $N = 5$ periyotlu, sıfırdan farklı sadece $a_0=1$, $a_2=e^{j\pi/4}$ ve $a_4=2e^{j\pi/3}$ Fourier serisi katsayılarına sahip reel değerli ayrık sinyal $x[n]$.
  • İstenen: $x[n]$ sinyalini $A_0 + \sum_{k=1}^{\infty} A_k \sin(\omega_k n + \phi_k)$ sinüs serisi formunda ifade etmek ve $A_0, A_k, \omega_k, \phi_k$ sabitlerini bulmak.
  • Kritik Ayrık Zaman Özelliği: DTFS katsayıları periyodiktir ($a_{k+5} = a_k$). Dolayısıyla $a_4 = a_{-1}$ ve $a_{-4} = a_1$'dir. Ayrıca kosinüsten sinüse geçişte $\cos\theta = \sin(\theta + \pi/2)$ özdeşliği uygulanır.

💡 Adım Adım Çözüm Metodolojisi

  1. Temel Açısal Frekans: $\omega_0 = 2\pi / N = 2\pi / 5$ rad hesaplanır.
  2. Reel Eşlenik Simetrisi: $a_{-2} = a_2^* = e^{-j\pi/4}$ ve $a_{-4} = a_4^* = 2e^{-j\pi/3}$ belirlenir.
  3. DTFS Sentez Denklemi: $x[n] = a_0 + (a_2 e^{j 2\omega_0 n} + a_{-2} e^{-j 2\omega_0 n}) + (a_4 e^{j 4\omega_0 n} + a_{-4} e^{-j 4\omega_0 n})$ yazılır.
  4. Sinüs Formuna Dönüşüm: Kosinüs terimleri $\cos\theta = \sin(\theta + \pi/2)$ ile sinüs faz açısına kaydırılır.

1. Adım

Temel Frekans ve DTFS Katsayılarının Periyodikliği

Verilen $x[n]$ ayrık zamanlı periyodik sinyalinin temel periyodu $N = 5$ örnektir. Temel açısal frekans $\omega_0$: $$\omega_0 = \frac{2\pi}{N} = \frac{2\pi}{5} \text{ rad}$$ Ayrık zaman Fourier serisi katsayıları $N = 5$ periyodu ile periyodiktir ($a_{k+5} = a_k$). Sıfırdan farklı verilen katsayılar: $$a_0 = 1, \quad a_2 = a_{-2}^* = e^{j\pi/4}, \quad a_4 = a_{-4}^* = 2e^{j\pi/3}$$ Periyodiklikten dolayı $a_{-1} = a_{-1+5} = a_4 = 2e^{j\pi/3}$ ve $a_1 = a_{1-5} = a_{-4} = 2e^{-j\pi/3}$ olur.

2. Adım

Reel Sinyallerde Eşlenik Simetrisi ($a_{-k} = a_k^*$)

$x[n]$ gerçel değerli olduğundan ($x^*[n] = x[n]$), katsayılar eşlenik simetrisini sağlar: $$x[n] \in \mathbb{R} \iff a_{-k} = a_k^*$$ - $k = 0$: $a_0 = 1$ (DC ortalama değer, saf reel). - $k = 2$: $a_2 = e^{j\pi/4} \implies a_{-2} = a_2^* = e^{-j\pi/4}$ (Genlik $|a_2| = 1$, Faz $\angle a_2 = \pi/4$). - $k = 4$: $a_4 = 2e^{j\pi/3} \implies a_{-4} = a_4^* = 2e^{-j\pi/3}$ (Genlik $|a_4| = 2$, Faz $\angle a_4 = \pi/3$).

3. Adım

DTFS Sentez Açılımı ve Eşlenik Çift Gruplama

Ayrık zaman Fourier serisi sentez denklemi tek bir $N = 5$ periyodu üzerinden yazılır: $$x[n] = \sum_{k=\langle 5 \rangle} a_k e^{j k \omega_0 n} = a_0 + \sum_{k=1, 2} \left( a_k e^{j k \omega_0 n} + a_{-k} e^{-j k \omega_0 n} \right)$$ Verilen katsayılar ile açılım: $$x[n] = 1 + \left( e^{j\pi/4} e^{j 2\omega_0 n} + e^{-j\pi/4} e^{-j 2\omega_0 n} \right) + \left( 2e^{j\pi/3} e^{j 4\omega_0 n} + 2e^{-j\pi/3} e^{-j 4\omega_0 n} \right)$$ Euler özdeşliğine göre her karmaşık eşlenik çift bir kosinüs dalgasına karşılık gelir: $a_k e^{jk\omega_0 n} + a_k^* e^{-jk\omega_0 n} = 2|a_k|\cos(k\omega_0 n + \angle a_k)$.

4. Adım

$k = \pm 2$ Harmonik Çiftinin Sinüs Dönüşümü

$k = \pm 2$ terimleri birleştirilir: $$x_2[n] = e^{j(2\omega_0 n + \pi/4)} + e^{-j(2\omega_0 n + \pi/4)} = 2\cos\left(2\omega_0 n + \frac{\pi}{4}\right) = 2\cos\left(\frac{4\pi}{5}n + \frac{\pi}{4}\right)$$ İstenen ifade sinüs formunda olduğundan $\cos\theta = \sin(\theta + \pi/2)$ özdeşliği uygulanır: $$x_2[n] = 2\sin\left(\frac{4\pi}{5}n + \frac{\pi}{4} + \frac{\pi}{2}\right) = 2\sin\left(\frac{4\pi}{5}n + \frac{3\pi}{4}\right)$$ Parametreler: $A_2 = 2, \quad \omega_2 = \frac{4\pi}{5} \text{ rad}, \quad \phi_2 = \frac{3\pi}{4} \text{ rad (135°)}$.

5. Adım

$k = \pm 4$ Harmonik Çiftinin Sinüs Dönüşümü

$k = \pm 4$ terimleri birleştirilir: $$x_4[n] = 2e^{j(4\omega_0 n + \pi/3)} + 2e^{-j(4\omega_0 n + \pi/3)} = 4\cos\left(4\omega_0 n + \frac{\pi}{3}\right) = 4\cos\left(\frac{8\pi}{5}n + \frac{\pi}{3}\right)$$ $\cos\theta = \sin(\theta + \pi/2)$ dönüşümü ile: $$x_4[n] = 4\sin\left(\frac{8\pi}{5}n + \frac{\pi}{3} + \frac{\pi}{2}\right) = 4\sin\left(\frac{8\pi}{5}n + \frac{5\pi}{6}\right)$$ *(Alternatif eşdeğer frekans: $\frac{8\pi}{5} \equiv -\frac{2\pi}{5} \implies 4\cos(\frac{2\pi}{5}n - \frac{\pi}{3}) = 4\sin(\frac{2\pi}{5}n + \frac{\pi}{6})$)* Parametreler: $A_4 = 4, \quad \omega_4 = \frac{8\pi}{5} \text{ rad}, \quad \phi_4 = \frac{5\pi}{6} \text{ rad (150°)}$.

6. Adım

Toplam Çıkış Sinyali $x[n]$ ve Parametre Tablosu

İstenen $x[n] = A_0 + \sum_{k=1}^{\infty} A_k \sin(\omega_k n + \phi_k)$ formundaki nihai analitik bağıntı: $$x[n] = 1 + 2\sin\left(\frac{4\pi}{5}n + \frac{3\pi}{4}\right) + 4\sin\left(\frac{8\pi}{5}n + \frac{5\pi}{6}\right)$$ veya temel frekans aralığında ($-\pi < \omega \le \pi$): $$x[n] = 1 + 4\sin\left(\frac{2\pi}{5}n + \frac{\pi}{6}\right) + 2\sin\left(\frac{4\pi}{5}n + \frac{3\pi}{4}\right)$$

Problem 3.9: Ayrık Zaman Periyodik Dürtü Katarının DTFS Katsayıları

$x[n] = \sum_{m=-\infty}^{\infty} \{4\delta[n - 4m] + 8\delta[n - 1 - 4m]\}$ periyodik ayrık zaman sinyalinin denklem (3.95) analiz eşitliği ile bir tam periyotluk ($k = 0, 1, 2, 3$) Fourier serisi katsayılarının kesin sayısal hesabı.

Verilen Ayrık Sinyal ve Bir Periyotluk Değerler:
$$N = 4, \quad x[0] = 4, \quad x[1] = 8, \quad x[2] = 0, \quad x[3] = 0$$
k = 0 $$a_0 = 3$$
k = 1 $$a_1 = 1 - 2j$$
k = 2 $$a_2 = -1$$
k = 3 $$a_3 = 1 + 2j$$
🎯

Soru Bizden Ne İstiyor?

  • Girdi: Her $4$ örnekte bir tekrarlayan ($N = 4$), $n=0$'da $4$, $n=1$'de $8$, $n=2$ ve $n=3$'te $0$ olan periyodik darbe katarı.
  • İstenen: Denklem (3.95) analiz formülü $a_k = \frac{1}{N} \sum_{n=0}^{N-1} x[n] e^{-j k \frac{2\pi}{N} n}$ ile bir periyotluk ($k = 0, 1, 2, 3$) sayısal katsayılar.
  • DTFS Temel Kuralı: Ayrık zamanda Fourier katsayıları da periyodiktir ($a_{k+N} = a_k$). Bu yüzden yalnızca $N = 4$ adet bağımsız katsayı vardır!
💡

Adım Adım Çözüm Metodolojisi

  1. Periyot Tespiti: $n - 4m \implies N = 4$ ve $\omega_0 = 2\pi / 4 = \pi / 2$.
  2. Temel Periyot Örnekleri: $x[0] = 4, x[1] = 8, x[2] = 0, x[3] = 0$.
  3. Analiz Toplamı: $a_k = \frac{1}{4}[4 e^0 + 8 e^{-j k \frac{\pi}{2}}] = 1 + 2 e^{-j k \pi/2}$.
  4. Sayısal Değerler: $e^{-j k \pi/2} = (-j)^k$ özdeşliği ile $k=0,1,2,3$ için değerlerin hesaplanması.
  5. Eşlenik Simetrisi Kontrolü: $x[n]$ gerçel olduğundan $a_3 = a_{-1} = a_1^*$ sağlaması.

Canlı Simülatör: DTFS Katsayı Spektrumu & Ayrık Zaman Stem Grafiği

Harmonik indeksini seçerek karmaşık düzlemdeki $a_k$ fazörünü ve $x[n]$ sinyalinin $N=4$ periyotluk darbe yapısını inceleyin.

Harmonik İndeksi ($k$): k = 1
Darbe Genliği Çarpanı: x1.0
DTFS Katsayıları $a_k$ (Mavi: Gerçel Kısım, Kırmızı: Sanal Kısım) N = 4 Periyodik Tekrar ($a_{k+4} = a_k$)
Ayrık Zaman Domeni $x[n]$ (Stem Grafiği) x[0]=4, x[1]=8, x[2]=0, x[3]=0
Hesaplanıyor...
1. Adım

Ayrık Zaman Sinyalinin Tanımı ve Temel Periyot ($N = 4$)

Verilen ayrık zaman sinyali: $$x[n] = \sum_{m=-\infty}^{\infty} \{4\delta[n - 4m] + 8\delta[n - 1 - 4m]\}$$ Darbelerin indekslerinde yer alan $4m$ terimi, sinyalin her $4$ örnekte bir kendini tam olarak tekrarladığını gösterir: $$\mathbf{N = 4 \text{ örnek}}, \quad \omega_0 = \frac{2\pi}{N} = \frac{2\pi}{4} = \frac{\pi}{2} \text{ rad/örnek}$$

2. Adım

Temel Periyot İçindeki Örnek Değerleri ($n = 0, 1, 2, 3$)

$m = 0$ periyoduna odaklanalım ($n = 0, 1, 2, 3$): $$n = 0 \implies x[0] = 4\delta[0] + 8\delta[-1] = 4 \cdot 1 + 0 = 4$$ $$n = 1 \implies x[1] = 4\delta[1] + 8\delta[0] = 0 + 8 \cdot 1 = 8$$ $$n = 2 \implies x[2] = 4\delta[2] + 8\delta[1] = 0$$ $$n = 3 \implies x[3] = 4\delta[3] + 8\delta[2] = 0$$ Bir periyotluk dizi: $\mathbf{x[n] = \{4, 8, 0, 0\}}, \quad 0 \le n \le 3$.

3. Adım

DTFS Analiz Denkleminin (3.95) Kurulması

Kitaptaki denklem (3.95): $$a_k = \frac{1}{N} \sum_{n=\langle N \rangle} x[n] e^{-j k \frac{2\pi}{N} n} = \frac{1}{4} \sum_{n=0}^{3} x[n] e^{-j k \frac{\pi}{2} n}$$ Örnek değerlerini yerine koyalım: $$a_k = \frac{1}{4} \left[ x[0] e^0 + x[1] e^{-j k \frac{\pi}{2}} + 0 + 0 \right] = \frac{1}{4} \left[ 4 + 8 e^{-j k \frac{\pi}{2}} \right]$$ $$\mathbf{a_k = 1 + 2 e^{-j k \frac{\pi}{2}} = 1 + 2(-j)^k}$$

4. Adım

Birebir Sayısal Katsayı Değerlerinin Hesaplanması

Temel periyot $k \in \{0, 1, 2, 3\}$ için açık hesaplamalar:

  • k = 0: $a_0 = 1 + 2 e^0 = 1 + 2 = \mathbf{3}$ (Ortalama değer: $(4+8+0+0)/4 = 3$).
  • k = 1: $a_1 = 1 + 2 e^{-j\pi/2} = 1 + 2(-j) = \mathbf{1 - 2j}$.
  • k = 2: $a_2 = 1 + 2 e^{-j\pi} = 1 + 2(-1) = 1 - 2 = \mathbf{-1}$.
  • k = 3: $a_3 = 1 + 2 e^{-j3\pi/2} = 1 + 2(j) = \mathbf{1 + 2j}$.

5. Adım

DTFS Periyodikliği ve Eşlenik Simetrisi Kontrolü

1. Periyodiklik: DTFS katsayıları $N=4$ periyodiktir ($a_{k+4} = a_k$): $$a_4 = a_0 = 3, \quad a_5 = a_1 = 1 - 2j, \quad a_6 = a_2 = -1, \quad a_7 = a_3 = 1 + 2j$$ 2. Eşlenik Simetrisi: $x[n]$ gerçel olduğu için $a_{-k} = a_k^*$ olmalıdır: $$a_3 = a_{3-4} = a_{-1} = 1 + 2j = (1 - 2j)^* = a_1^* \quad \text{(Kusursuz Sağlar!)}$$ $$a_2 = a_{-2} = -1 = (-1)^* \quad \text{(Gerçel ve Simetrik)}$$

6. Adım

Parseval Güç Korunumu ve Sonuç Tablosu

Parseval eşitliği ile sağlamasını yapalım: $$\text{Zaman Domeni Gücü: } P = \frac{1}{4} \sum_{n=0}^3 |x[n]|^2 = \frac{1}{4} [4^2 + 8^2 + 0 + 0] = \frac{16 + 64}{4} = \frac{80}{4} = 20$$ $$\text{Frekans Domeni Gücü: } \sum_{k=0}^3 |a_k|^2 = |3|^2 + |1-2j|^2 + |-1|^2 + |1+2j|^2 = 9 + (1+4) + 1 + (1+4) = 9 + 5 + 1 + 5 = 20$$ İki taraf tam eşittir ($20 = 20$).

Sürekli Zaman (Continuous-Time) Oppenheim Problem 2.22 (e) / Şekil P2.22(c)

Problem 2.22 (e) — Periyodik Kare Dalga ve Üçgen Darbe Konvolüsyonu

$$x(t) = \text{Periyodik Kare Dalga } (T = 2), \quad h(t) = (1 - t)[u(t) - u(t-1)] \quad \Longrightarrow \quad y(t) = x(t) * h(t) = \int_{-\infty}^{\infty} h(\tau) x(t - \tau) d\tau$$ Periyodik bir giriş sinyalinin sonlu süreli bir dürtü yanıtıyla konvolüsyonu, aynı temel periyoda ($T = 2$) sahip periyodik bir çıkış üretir. Çıkış eğrisi $C^1$ sürekliliğinde ardışık parabollerden oluşur.

Soru Analizi & Mini Konu Anlatımı

Periyodik sinyallerin konvolüsyonu: Temel periyodun korunması ve parabol dalgası

🎯 Soru Bizden Ne İstiyor?

  • Sinyaller: $x(t)$ temel periyodu $T = 2$ olan periyodik kare dalgadır ($[0, 1)$'de $+1$, $[1, 2)$'de $-1$). $h(t) = (1 - t)[u(t) - u(t-1)]$ ise sonlu süreli sağ üçgen darbedir.
  • İstenen: $y(t) = x(t) * h(t)$ konvolüsyonunu bulup periyodik dalga formunu çizmek.
  • Teorem: Bir periyodik sinyal ($T$) ile kararlı sonlu süreli bir dürtü yanıtının konvolüsyonu, aynı $T$ temel periyoduna sahip periyodik bir sinyal üretir!

💡 Adım Adım Çözüm Metodolojisi

  1. Entegrasyon Penceresi: $h(t- au) eq 0 \iff t-1 \le au \le t$. Pencere genişliği daima $1$ birimdir.
  2. Aralık 1 ($0 \le t \le 1$): $[t-1, 0]$ aralığında $x=-1$, $[0, t]$ aralığında $x=+1$ ile kesişir: $y(t) = -t^2 + 2t - 1/2$. ($t=1$'de tepe $0.5$).
  3. Aralık 2 ($1 \le t \le 2$): $[t-1, 1]$ aralığında $x=+1$, $[1, t]$ aralığında $x=-1$ ile kesişir: $y(t) = t^2 - 4t + 7/2$. ($t=2$'de dip $-0.5$).
  4. Periyodik Genişleme: Tüm $t \in \mathbb{R}$ için $y(t) = y(t + 2k)$ olur; dalga formu $C^1$ mertebesinde pürüzsüz parabol dizisidir.

1. Adım

1. Adım: Sinyallerin Matematiksel Yapısı ve $\tau$ Dönüşümü

Kitaptaki Şekil P2.22(c)'ye göre giriş ve dürtü yanıtı şu şekilde tanımlanır: $$x(\tau) = \begin{cases} +1, & 0 \le \tau < 1 \\ -1, & 1 \le \tau < 2 \end{cases}, \quad x(\tau + 2) = x(\tau) \quad (\text{Periyot } T = 2)$$ $$h(\tau) = (1 - \tau)[u(\tau) - u(\tau - 1)] \quad (\tau = 0\text{'da } 1, \tau = 1\text{'de } 0\text{ olan dik üçgen})$$

2. Adım

2. Adım: Katlama (Zaman Tersleme - Time Reversal) $\to h(-\tau)$

$h(\tau)$ sinyali dikey eksene ($\tau = 0$) göre aynalanır ($\tau \to -\tau$): $$h(-\tau) = (1 + \tau)[u(-\tau) - u(-\tau - 1)]$$ Üçgen darbe $[-1, 0]$ aralığına geçer. Tepe noktası yine $\tau = 0$'dadır ($h(0)=1$) ve sola doğru azalarak $\tau = -1$'de sıfırlanır.

3. Adım

3. Adım: Parametrik Zamanda Öteleme $\to h(t - \tau)$

Katlanmış üçgen $t$ kadar sağa kaydırılır: $$h(t - \tau) = (1 - (t - \tau)) = (1 - t + \tau), \quad \text{için } t - 1 \le \tau \le t$$ Entegrasyon penceresi tam olarak $[t - 1, t]$ aralığıdır ve genişliği sabit $1$ birimdir. Tepe noktası $\tau = t$'de, sol kuyruk ise $\tau = t - 1$'dedir.

4. Adım

4. Adım: 1. Alt Aralık ($0 \le t \le 1$) $\to y(t) = -t^2 + 2t - \frac{1}{2}$

$0 \le t \le 1$ aralığında $[t-1, t]$ penceresi $\tau = 0$ sınırını kapsar: $[t-1, 0]$ aralığında $x(\tau) = -1$, $[0, t]$ aralığında ise $x(\tau) = +1$'dir.

Bölge 1 Analitik İntegral Hesabı ($0 \le t \le 1$):
$$y(t) = \int_{t-1}^{0} (-1)(1 - t + \tau) d\tau + \int_{0}^{t} (+1)(1 - t + \tau) d\tau$$

1. parça (negatif blok katkısı):

$$-\int_{t-1}^{0} (1 - t + \tau) d\tau = -\left[ (1 - t)\tau + \frac{\tau^2}{2} \right]_{t-1}^{0} = -\left(0 - \left[(1-t)(t-1) + \frac{(t-1)^2}{2}\right]\right) = -\frac{(t-1)^2}{2}$$

2. parça (pozitif blok katkısı):

$$\int_{0}^{t} (1 - t + \tau) d\tau = \left[ (1 - t)\tau + \frac{\tau^2}{2} \right]_{0}^{t} = (1 - t)t + \frac{t^2}{2} = t - \frac{t^2}{2}$$

Toplam:

$$y(t) = -\frac{t^2 - 2t + 1}{2} + t - \frac{t^2}{2} = \mathbf{-t^2 + 2t - \frac{1}{2}} = \mathbf{-(t - 1)^2 + \frac{1}{2}} \quad (0 \le t \le 1)$$
$y(0) = -0.5$, $y(0.5) = +0.25$, $t = 1$'de tepe değeri: $y(1) = 0.5$.
5. Adım

5. Adım: 2. Alt Aralık ($1 \le t \le 2$) $\to y(t) = t^2 - 4t + \frac{7}{2}$

$1 \le t \le 2$ aralığında $[t-1, t]$ penceresi $\tau = 1$ sınırını kapsar: $[t-1, 1]$ aralığında $x(\tau) = +1$, $[1, t]$ aralığında ise $x(\tau) = -1$'dir.

Bölge 2 Analitik İntegral Hesabı ($1 \le t \le 2$):
$$y(t) = \int_{t-1}^{1} (+1)(1 - t + \tau) d\tau + \int_{1}^{t} (-1)(1 - t + \tau) d\tau$$

1. parça (pozitif blok katkısı):

$$\int_{t-1}^{1} (1 - t + \tau) d\tau = \left[ (1 - t)\tau + \frac{\tau^2}{2} \right]_{t-1}^{1} = \frac{1}{2}(t - 2)^2 = \frac{t^2}{2} - 2t + 2$$

2. parça (negatif blok katkısı):

$$-\int_{1}^{t} (1 - t + \tau) d\tau = -\left( \left[ (1 - t)\tau + \frac{\tau^2}{2} \right]_{1}^{t} \right) = \frac{t^2}{2} - 2t + \frac{3}{2}$$

Toplam:

$$y(t) = \left(\frac{t^2}{2} - 2t + 2\right) + \left(\frac{t^2}{2} - 2t + \frac{3}{2}\right) = \mathbf{t^2 - 4t + \frac{7}{2}} = \mathbf{(t - 2)^2 - \frac{1}{2}} \quad (1 \le t \le 2)$$
$y(1) = 0.5$ (sol parçayla mükemmel eşleşir), $y(1.5) = -0.25$, $t = 2$'de dip değeri: $y(2) = -0.5$.
6. Adım

6. Adım: Sistemin Toplam Çıkış Yanıtı $y(t)$ (Periyodik Parabol Dalgası)

$x(t)$ sinyali periyodik olduğundan, konvolüsyon çıkışı $y(t)$ de $T = 2$ periyoduyla sonsuza kadar kendini tekrarlar: $$y(t) = \begin{cases} \displaystyle -t^2 + 2t - \frac{1}{2}, & 0 \le t \le 1 \\[1.5ex] \displaystyle t^2 - 4t + \frac{7}{2}, & 1 \le t \le 2 \end{cases}, \qquad y(t + 2) = y(t)$$ Dalga formu tepe ve dip noktalarında $C^1$ mertebesinde pürüzsüzdür: $y'(1) = 0$, $y'(2) = 0$, $y'(0) = 0$.

Problem 3.27: DTFS Katsayılarından Harmonik Sinüs Formunun Elde Edilmesi

Periyodu $N = 5$ olan gerçel değerli bir $x[n]$ sinyalinin verilen Fourier serisi katsayıları $a_0 = 2$, $a_2 = 2e^{j\pi/6}$, $a_4 = e^{j\pi/3}$ üzerinden eşlenik simetri ve $N$-periyodiklik kullanılarak $x[n] = A_0 + \sum_{k=1}^2 A_k \sin(\omega_k n + \phi_k)$ standart trigonometrik sinüs formuna dönüştürülmesi.

Verilenler: $N = 5, \quad a_0 = 2, \quad a_2 = a_{-2}^* = 2e^{j\pi/6}, \quad a_4 = a_{-4}^* = e^{j\pi/3}$
Temel Frekans: $\omega_0 = \frac{2\pi}{N} = \frac{2\pi}{5}\text{ rad}$
Hedef Form: $x[n] = A_0 + A_1 \sin(\omega_1 n + \phi_1) + A_2 \sin(\omega_2 n + \phi_2) \quad (A_k \ge 0, \, 0 \le \phi_k < 2\pi)$

Soru Analizi & Mini Konu Anlatımı

🎯 Soru Bizden Ne İstiyor?

  • $N = 5$ periyodiklik ve $x[n]$ gerçellik koşullarından tüm katsayıların ($a_0, a_1, a_2, a_3, a_4$) kutupsal formda eksiksiz bulunması.
  • Kompleks üstel harmonik çiftlerinin kosinüse çevrilmesi: $a_k e^{jk\omega_0 n} + a_{-k} e^{-jk\omega_0 n} = 2|a_k|\cos(k\omega_0 n + \theta_k)$.
  • Trigonometrik özdeşlik $\cos(\alpha) = \sin(\alpha + \pi/2)$ ile istenen pozitif genlikli ve fazlı sinüs formunun ($A_k \ge 0, \phi_k \in [0, 2\pi)$) elde edilmesi.

💡 DTFS'de Periyodiklik ve Eşlenik Simetri

Ayrık zaman Fourier katsayıları $N$ periyotludur: $a_{k+N} = a_k$. $N=5$ için:

a_{-1} = a_{4}, \quad a_{-2} = a_{3}

Sinyal gerçel değerli olduğundan eşlenik simetri şartı $a_{-k} = a_k^*$ geçerlidir. Bu nedenle $a_1 = a_{-1}^* = a_4^*$ ve $a_3 = a_{-2} = a_2^*$ bağıntıları tüm spektrumu tek hamlede belirler.

DTFS Periyodikliği ve Modulo-5 Eşleşmeleri

Modulo-5 Özelliği

Ayrık zaman Fourier serisi katsayıları $N$-periyodiktir. Burada temel periyot $N = 5$ olduğundan her $k$ için $a_{k+5} = a_k$ geçerlidir.

Bize verilen katsayılar: $$a_0 = 2$$ $$a_2 = 2e^{j\pi/6}$$ $$a_4 = e^{j\pi/3}$$

Modulo 5 aritmetiği ile negatif harmonikleri pozitif aralığa eşleştirelim: $$a_{-1} = a_{-1 + 5} = a_4 = e^{j\pi/3}$$ $$a_{-2} = a_{-2 + 5} = a_3 = a_2^* = 2e^{-j\pi/6}$$

2

Gerçellik Şartı ile a1 Katsayısının Bulunması

Eşlenik Simetri

Soru metninde $x[n]$'in gerçel değerli (real-valued) olduğu belirtilmiştir. Gerçel sinyaller için katsayılar eşlenik simetridir:

$$a_{-k} = a_k^* \iff a_k = a_{-k}^*$$

1. Adımda $a_{-1} = a_4 = e^{j\pi/3}$ olarak bulmuştuk. Dolayısıyla $a_1$ katsayısı:

$$a_1 = a_{-1}^* = (e^{j\pi/3})^* = e^{-j\pi/3}$$

Böylece bir temel periyot içindeki tüm katsayılar ($k \in [0, 4]$) belirlenmiş olur: $$a_0 = 2, \quad a_1 = e^{-j\pi/3}, \quad a_2 = 2e^{j\pi/6}, \quad a_3 = 2e^{-j\pi/6}, \quad a_4 = e^{j\pi/3}$$

3

DTFS Sentezi ve Kosinüs Formu Gruplaması

Sentez Denklemi

Ayrık zaman Fourier serisi sentez denklemini $k = -2, -1, 0, 1, 2$ simetrik aralığında yazalım:

$$x[n] = \sum_{k=\langle 5 \rangle} a_k e^{jk\omega_0 n} = a_0 + (a_1 e^{j\omega_0 n} + a_{-1} e^{-j\omega_0 n}) + (a_2 e^{j2\omega_0 n} + a_{-2} e^{-j2\omega_0 n})$$

$a_{-k} = a_k^*$ olduğundan her harmonik çifti bir kosinüs oluşturur: $$a_k e^{jk\omega_0 n} + a_k^* e^{-jk\omega_0 n} = 2 |a_k| \cos(k\omega_0 n + \angle a_k)$$

Temel açısal frekans $\omega_0 = \frac{2\pi}{5}$ rad/örnek'tir.

4

Harmoniklerin Kosinüslü Açılımı

Kosinüs Formu

Bileşenleri ayrı ayrı hesaplayalım:

  • DC Bileşen: $A_0 = a_0 = 2$.
  • 1. Harmonik (k = 1): $$|a_1| = 1, \quad \angle a_1 = -\frac{\pi}{3}$$ $$x_1[n] = 2(1)\cos\left(\frac{2\pi}{5}n - \frac{\pi}{3}\right) = 2\cos\left(\frac{2\pi}{5}n - \frac{\pi}{3}\right)$$
  • 2. Harmonik (k = 2): $$|a_2| = 2, \quad \angle a_2 = \frac{\pi}{6}$$ $$x_2[n] = 2(2)\cos\left(\frac{4\pi}{5}n + \frac{\pi}{6}\right) = 4\cos\left(\frac{4\pi}{5}n + \frac{\pi}{6}\right)$$
$$x[n] = 2 + 2\cos\left(\frac{2\pi}{5}n - \frac{\pi}{3}\right) + 4\cos\left(\frac{4\pi}{5}n + \frac{\pi}{6}\right)$$
5

Kosinüsten İstenen Sinüs Formuna Dönüşüm

Faz Kaydırma

Soruda ifadenin sinüs cinsinden yazılması istenmektedir: $$\cos(\theta) = \sin\left(\theta + \frac{\pi}{2}\right)$$

Bu dönüşümü her iki harmoniğe uygulayalım:

  • 1. Harmonik için: $$\phi_1 = -\frac{\pi}{3} + \frac{\pi}{2} = \frac{\pi}{6}$$ $$2\cos\left(\frac{2\pi}{5}n - \frac{\pi}{3}\right) = 2\sin\left(\frac{2\pi}{5}n + \frac{\pi}{6}\right)$$
  • 2. Harmonik için: $$\phi_2 = \frac{\pi}{6} + \frac{\pi}{2} = \frac{4\pi}{6} = \frac{2\pi}{3}$$ $$4\cos\left(\frac{4\pi}{5}n + \frac{\pi}{6}\right) = 4\sin\left(\frac{4\pi}{5}n + \frac{2\pi}{3}\right)$$
$$x[n] = 2 + 2\sin\left(\frac{2\pi}{5}n + \frac{\pi}{6}\right) + 4\sin\left(\frac{4\pi}{5}n + \frac{2\pi}{3}\right)$$
